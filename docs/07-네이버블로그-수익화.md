# 네이버 블로그 수익화

강의(5강)는 네이버 블로그를 "외부 유입" 수단으로 소개하지만, 이 프로젝트에서는
**독립 수익 채널**로 함께 운영합니다. 서버·도메인 없이 **무료로 즉시 시작**할 수 있습니다.

## 왜 네이버 블로그를 병행하는가

- 신규 워드프레스 글은 검색 상위 노출까지 시간이 걸림 → 네이버 블로그는 네이버 검색에 상대적으로 빠르게 노출
- 수익원이 두 가지:
  1. **제휴링크** (쿠팡 파트너스 등) — 워드프레스와 동일한 제휴 수익
  2. **네이버 애드포스트** — 네이버 블로그 자체 광고 수익 (애드센스와 유사한 구조)
- ⚠️ 노출·수익 증가는 보장되지 않습니다. 채널별 성과를 분리해 측정하세요.

## 두 수익원 비교

| 수익원 | 승인 필요 | 구조 | 비고 |
|---|---|---|---|
| 제휴링크 | 제휴처 가입 + **미디어 등록** | 링크 → 구매 → 수수료 | 광고표시 필수 |
| 애드포스트 | 네이버 애드포스트 별도 승인 | 광고 노출/클릭 | 블로그 품질·활동 기준 |

애드포스트: https://adpost.naver.com/

## 세팅 순서

### 1. 네이버 블로그 개설·정비
- 블로그 주제를 세컨/서드 블로그와 **연계된 니치**로 (예: 여행 할인·가전 리뷰)
- 카테고리·프로필 정비
- 📝 `data/niche.yaml`의 `naver_blog.url` 기록

### 2. 애드포스트 가입 신청
- 애드포스트 → 미디어 등록 → 블로그 연결 → 심사
- ⚠️ 승인 기준(활동 기간·품질)은 네이버 정책에 따름. 즉시 승인 아님
- 승인되면 `naver_blog.adpost_joined: true`

### 3. 제휴처에 네이버 블로그를 미디어로 등록
- 쿠팡 파트너스 → 미디어 관리 → **네이버 블로그 URL 등록**
- ⚠️ 미등록 미디어에서 광고 노출은 금지행위 (쿠팡 정책)
- `affiliate_programs`의 `media_registered` 갱신

## 글쓰기 원칙 (워드프레스와 다른 점)

기본 구조는 [`../templates/글-구조-템플릿.md`](../templates/글-구조-템플릿.md)와 같지만,
네이버 블로그는 아래를 특히 지킵니다.

| 항목 | 네이버 블로그에서 |
|---|---|
| **원문 복제 금지** | 워드프레스 글을 그대로 붙여넣지 말 것. **네이버 독자용으로 재작성** |
| **광고 표시** | 제휴링크 글은 제목/첫 부분에 경제적 이해관계 공개 (공정위) |
| **이미지** | 직접 촬영/라이선스 확인. 무단 캡처 금지 |
| **링크** | 쿠팡 등 제휴링크는 공식 생성 링크. 클릭 강요 문구 금지 |
| **스팸 방지** | 같은 글 도배·반복 링크 금지 |

> 워드프레스 ↔ 네이버 블로그는 **같은 주제를 각 독자에 맞게 다르게** 씁니다.
> 한쪽을 그대로 복제하면 중복 콘텐츠 + 품질 저하로 양쪽 다 손해입니다.

## 발행 전 검사

제휴링크가 들어간 네이버 블로그 글도 동일하게 검사합니다.
```bash
python3 tools/compliance.py drafts/네이버-글.md --affiliate
```

## 워드프레스와의 연계

| 방식 | 설명 |
|---|---|
| 독립 발행 | 네이버 블로그에 완결된 제휴 글 (제휴링크 + 애드포스트) |
| 유입 보조 | 네이버 블로그 → 워드프레스 심화 글로 자연스럽게 연결 (도배 아님) |

⚠️ "유입 보조"는 강의의 외부 유입 전략과 같습니다. **실제로 도움 되는 글** 안에서만.
지식인·카페 도배는 금지 → [`90-정책-준수-가이드.md`](90-정책-준수-가이드.md) 4번
