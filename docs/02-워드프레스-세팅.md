# Day 1-2 — 워드프레스 개설 + 최적화 세팅 (1강 · 2강)

블로그당 **한 번만** 하는 작업입니다. 이후에는 건드릴 필요가 없습니다.
2번째 블로그를 만들 때(4강) 이 문서를 그대로 다시 씁니다.

---

## Part A — 워드프레스 개설 (1강)

### A-1. 호스팅 가입
1. 호스팅 서비스에 구글/카카오/네이버/이메일로 가입
2. 약관 동의 → 주소 등록 (영문 이름 + 실주소) → 전화번호 등록(알림톡 수신용)
3. ⚠️ **공식 도메인인지 확인**. 검색 광고로 뜨는 유사 사이트 주의

### A-2. 도메인 구매
1. "워드프레스 시작하기" → 도메인 검색
2. `.com` / `.co.kr` / `.kr` 중 선택 (소문자만)
3. 결제 → 연 1회 갱신
4. 📝 기록: 구매한 도메인, 갱신일

### A-3. 워드프레스 생성
1. 블로그 이름 입력
2. 관리자 ID / **강한 비밀번호** 지정 → 📝 비밀번호 관리자에 저장
3. "하나의 블로그만 운영" 선택 (나중에 추가 가능)
4. 서버 결제 (강의 기준 월 31,900원)
5. 프로비저닝 5~10분 대기 → 서버·블로그 "가동 중" 확인

### A-4. 관리자 로그인 + 초기 연결
1. 관리자 주소(`/wp-admin`)로 로그인
2. **북마크 등록** (`Ctrl+D`) → 이름을 "OO 관리자"로 정리
3. 브릿지 테마 어시스턴트 → "블로그" → "간편한" 테마 자동 설치·활성화
4. 알팩(Alpack) 플러그인 → 카카오 로그인으로 활성화 (무료 기능)

> ⚠️ 알팩은 강사 제작 플러그인입니다. 무료 기능 10종은 쓸 수 있으나, 종속성을 감안하세요.
> AI 블로그 포스팅 기능은 유료입니다.

## Part B — 최적화 세팅 (2강)

**이 순서대로** 하면 막히지 않습니다.

### B-1. 테마
- 모양 → 테마 추가 → **GeneratePress** 설치·활성화
- 미사용 기본 테마 삭제 (대체 테마 1개만 남김)

### B-2. 카테고리
- 글 → 카테고리 → 주제별 생성
- 각 카테고리에 **짧은 영문 슬러그** (구글 번역기로 변환)
- ⚠️ **1번 블로그(애드센스용)는 승인 전까지 카테고리 1개만.** 3강 참고
- ⚠️ 실제로 글을 쓸 카테고리만. 빈 카테고리를 늘리지 말 것

### B-3. 메뉴
- 외모 → 메뉴 → 메뉴 이름 "Header Menu" → 메뉴 생성
- 카테고리 → 모두 보기 → 체크 → 메뉴에 추가 → 저장
- 순서는 드래그로 조정

### B-4. 파비콘
- ChatGPT에 "(주제) 관련 파비콘 만들어줘" → 다운로드
- 설정 → 일반 → 사이트 아이콘 → 업로드 → 정사각형으로 자르기
- **제목·대체텍스트·설명 입력** (접근성)

### B-5. 사이트 제목·태그라인
- 설정 → 일반 → 사이트 제목(브랜드), 태그라인(영문)
- 붙여넣기 전 **입력란을 먼저 클릭**해야 함

### B-6. 알팩 기능 활성화
- 빠른 버튼 생성: 플러그인 기능 활성화 + 애니메이션 무한반복 활성화 → 저장
- Header & Footer: 활성화 (검색엔진 인증 코드 넣는 공간)
- Seen Analytics: 활성화 (방문자 통계, 무료)

### B-7. Rank Math (SEO)
1. 플러그인 → 추가 → "Rank Math SEO" 검색 → 설치·활성화
2. Connect Your Account → Google 로그인
3. 시작 마법사:
   - 웹사이트 이름 / 대체 이름(짧은 영문) / 로고 업로드
   - Google 서비스 연결
   - 이메일 리포트 **체크 해제**
   - 외부 링크 팔로우 안 함 체크 → 저장 후 계속
   - 404 모니터 체크, Redirection 체크 → 저장 후 계속
   - **Content AI 체크 해제** (유료)

> ⚠️ "외부 링크 전부 nofollow"는 만능이 아닙니다. 광고·후원 링크는 `rel="sponsored"`,
> 신뢰할 수 없는 링크만 `nofollow`가 구글 공식 안내에 가깝습니다. 인용 링크까지 막지 마세요.

### B-8. 첫 글 1개 발행
사이트맵은 **글이 최소 1개** 있어야 생성됩니다.
- 글 → 새 글 → 발행 (더미 "안녕하세요"보다 **실제 유용한 첫 글**이 안전)
- 확인: `https://내도메인/sitemap_index.xml` 이 정상적으로 뜨는가

### B-9. 검색엔진 등록 4곳

공통 방식: 각 도구에서 받은 **HTML 태그를 알팩 → Header & Footer의 헤더 코드에 붙여넣고 저장** → 소유권 확인.

| 순서 | 검색엔진 | 핵심 |
|---|---|---|
| 1 | **네이버 서치어드바이저** | HTML 태그 인증 → 사이트맵(`/sitemap_index.xml`) + RSS(`/feed`) 제출 → 웹페이지 수집 요청. **반드시 `https://`** |
| 2 | **구글 서치콘솔** | Rank Math 연결 시 자동 등록되는 경우 많음. 사이트맵 제출 + URL 검사 → 색인 생성 요청 |
| 3 | **Bing 웹마스터** | 구글 계정 로그인 → 메타 태그 인증 → 사이트맵 제출 |
| 4 | **Daum 검색등록** | PIN 코드 발급 + robots.txt 설정 → 문서/RSS/사이트맵 제출 |

> 📝 검색엔진별 소유권 확인 태그는 **사이트마다 다릅니다.** 2번 블로그와 혼동하지 않게
> 사이트별로 구분해서 기록하세요.

> ⚠️ 등록은 색인이나 상위 노출을 **보장하지 않습니다.** 검색엔진에게 "존재를 알리는" 작업일 뿐입니다.

## 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 사이트맵이 "찾을 수 없음" | 글이 0개 | 글 1개 발행 후 재시도 |
| 사이트맵/RSS 등록이 안 됨 | 캐시 | 호스팅 콘솔 → CloudFront 캐시 삭제 후 재시도 |
| Rank Math에 사이트맵이 안 뜸 | 모듈 비활성 | Rank Math → 사이트맵 모듈 활성화 |
| 검색엔진 소유권 확인 실패 | 태그 위치 오류 | 헤더 코드 영역에 정확히 붙였는지, 저장했는지 확인 |
