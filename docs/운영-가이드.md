## 0. 이 프로젝트의 실행 구조

**Claude 세션은 블로그 도메인에 직접 접근할 수 없다.** (네트워크 차단)
모든 워드프레스 작업은 **GitHub Actions 러너**가 대신한다.

```
Claude → 워크플로우 dispatch → 러너가 WP REST API 호출 → 로그 출력 → Claude가 로그를 읽어 확인
```

그래서 지켜야 할 것:
- 새 워크플로우는 **main에 머지된 뒤에야** 실행할 수 있다 (GitHub 제약)
- 결과 확인은 항상 **로그를 읽어서** 한다. "됐을 것이다"로 넘기지 않는다

### 필요한 시크릿
| 이름 | 용도 |
|---|---|
| `WP_URL` | 블로그 주소 |
| `WP_USER` | 워드프레스 사용자 |
| `WP_APP_PASSWORD` | **응용 프로그램 비밀번호** (관리자 비밀번호 아님) |
| `OPENAI_API_KEY` 또는 `OPEN_API_KEY` | AI 썸네일·본문 이미지 생성 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 지식iN 글감 조사 (네이버 클라우드 API HUB 키) |

## 1. 새 글 발행 — 표준 순서

### 준비
1. **주제 선정** — `docs/콘텐츠-로드맵.md`에서 고른다
2. **구조 결정** — `templates/제휴글-스타일가이드.md` 3.5 F 이력표를 보고 **최근 4편과 겹치지 않는 조합**을 고른다
3. **초안 작성** — `drafts/예시-<주제>.md`
   - 파일명은 반드시 `예시-`로 시작 (그 외 drafts는 gitignore됨)
   - 본문에 `[[IMG:키]]`, `[[PRODUCT:키]]` 토큰을 넣는다
4. **인포그래픽** — `assets/images/<키>/<이름>.svg` + 같은 폴더에 `alt.json`
5. **상품카드** — `assets/products/<키>.html`
   - 운영자가 준 **쿠팡 배너 HTML**(`<a href="link.coupang.com/a/..."><img src="...coupangcdn..."></a>`)에서 링크·이미지를 뽑아 카드로 조립
   - ⚠️ **iframe 배너는 쓸 수 없다.** 이미지 배너로 다시 받는다
6. **머지** — PR 만들어 main에 머지 (워크플로우가 파일을 읽으려면 main에 있어야 함)

### 발행 (순서대로)
```
① wp-rewrite-post.yml      새 글 발행 (post_id 비우면 신규)
② wp-set-slug-tags.yml     영문 슬러그 + 태그 + 카테고리
③ wp-rehost-all.yml        쿠팡 배너 이미지를 우리 서버로 이전
④ wp-add-dynamic-banner.yml 하단 캐러셀 삽입
⑤ wp-inspect.yml           검증
```

**②~⑤는 ①이 완전히 끝난 뒤에 실행한다.** ①은 AI 이미지 2장 생성 때문에 약 2분 걸리고,
끝나기 전에 ③을 돌리면 리호스팅이 덮어써져 무효가 된다(실제로 겪은 실수).

### ①의 주요 입력값
| 입력 | 설명 |
|---|---|
| `post_id` | 비우면 신규 발행, 채우면 해당 글 재빌드 |
| `draft_path` | `drafts/예시-....md` |
| `image_dir` | `assets/images/<키>` (이 폴더의 SVG만 변환) |
| `product_dir` | `assets/products` 고정 |
| `category_name` | 정확한 카테고리 이름 |
| `thumb_prompt` / `mid_prompt` | AI 이미지 프롬프트 (영문, `no text, no logos` 필수) |
| `mid_anchor` | 중간 이미지를 넣을 **H2 제목과 정확히 일치**해야 함 |
| `status` | `publish` / `draft` |

### 발행 후 (운영자가 직접)
- **Rank Math 포커스 키워드 입력** — REST로 저장이 안 되는 항목이라 수동
  - ⚠️ **편집기를 새로고침한 뒤에** 입력할 것. 열어둔 낡은 탭을 저장하면 REST로 넣은 내용이 통째로 덮어써진다
- 메타 설명은 자동 생성되므로 굳이 손대지 않아도 된다

## 2. 워크플로우 카탈로그

### 발행·수정
| 파일 | 용도 |
|---|---|
| `wp-rewrite-post.yml` | **주력.** 초안 → 발행/재빌드 (이미지·상품카드·광고문구 전부 처리) |
| `wp-set-slug-tags.yml` | 슬러그·태그·카테고리 설정. `create_category=y`로 새 카테고리 생성 가능 |
| `wp-add-dynamic-banner.yml` | 모든 발행 글 하단에 쿠팡 캐러셀 삽입 (멱등) |
| `wp-rehost-all.yml` | 쿠팡 CDN 이미지를 우리 미디어로 이전 (**광고차단 대응**) |
| `wp-publish.yml` / `wp-full-post.yml` | 구버전 발행 경로 |
| `wp-insert-product.yml` / `wp-remove-product.yml` | 상품카드만 넣고 빼기 |
| `wp-insert-image.yml` / `wp-upload-image.yml` / `wp-images.yml` / `wp-thumbnail.yml` | 이미지 개별 작업 |
| `wp-style-disclosure.yml` / `wp-strip-disclosure.yml` | 광고표시 문구 스타일 변경·제거 |

### SEO
| 파일 | 용도 |
|---|---|
| `wp-seo-patch.yml` | 키워드 배치·내부링크·외부링크 주입 (글별 PLAN 하드코딩) |
| `wp-seo-apply.yml` | 슬러그·태그·제목 일괄 적용 |
| `wp-seo-expand.yml` | 분량 보강 |
| `wp-seo-audit.yml` / `wp-seo-meta.yml` | 진단 |

### 진단
| 파일 | 용도 |
|---|---|
| `wp-list-posts.yml` | **전체 글 상태 점검** — 상품카드·쿠팡링크·광고문구·다이나믹배너·내부링크 수 |
| `wp-inspect.yml` | 특정 글 본문 발췌 + 항목 체크 |
| `wp-status.yml` / `wp-settings.yml` | 사이트 설정 확인 |
| `site-check.yml` | 공개 페이지 확인 (인증 태그·robots.txt·사이트맵) |

### 지식iN
| 파일 | 용도 |
|---|---|
| `kin-unanswered.yml` | **주력.** 지금 시점 **답변 0개** 질문을 최신순으로 조회 |
| `naver-kin-find.yml` | 키워드 기반 글감 조사 (검색 API). **미답변은 못 찾는다** — 아래 참고 |

> 네이버 검색 API는 **답변이 달린 글만 색인**한다. 그래서 미답변 질문은 검색으로 찾을 수 없고,
> 카테고리 목록 페이지를 직접 파싱하는 `kin-unanswered.yml`을 써야 한다.
> 두 도구는 용도가 다르다 — 조사는 `naver-kin-find`, 답변 대상 찾기는 `kin-unanswered`.

## 3. 지식iN 홍보

자세한 규칙은 `templates/제휴글-스타일가이드.md` **8절**. 요약하면:

- 답변 본문에서 **특정 제품을 추천하지 않는다** (지식iN 정책이 겨냥하는 형태)
- **쿠팡 링크를 답변에 직접 붙이지 않는다** (자동 필터 삭제·정지 위험)
- 블로그 링크를 달면 **끝부분에 제휴 관계를 공개**한다
- 링크는 **출처 칸**에, 하루 3답변 중 **링크는 1개까지**, 대상 글은 매번 다르게
- 답변 텍스트는 **코드블록으로 전달** (서식이 딸려가 배경색·글자색이 깨진다)

**현재 전략:** 계정이 초수이고 중수까지 채택 답변이 부족하다.
링크 있는 답변은 채택률이 낮으므로, **답변 0개인 최신 질문에 빠르게 답해 채택을 먼저 쌓는다.**

## 4. 자주 겪은 문제와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 쿠팡 배너가 안 보임 | 광고차단기가 `coupangcdn.com/image/affiliate/banner/` 차단 | `wp-rehost-all.yml`로 우리 서버 이전 |
| 하단 캐러셀이 안 보임 | `ads-partners.coupang.com/g.js`는 실시간 JS라 리호스팅 불가 | 광고차단 사용자에게는 안 보이는 게 정상 |
| Rank Math 점수가 되돌아감 | 낡은 편집기 탭을 저장해 REST 변경분을 덮어씀 | 편집기 **새로고침 후** 작업 |
| 포커스 키워드가 REST로 저장 안 됨 | Rank Math 메타는 REST 미지원 | 수동 입력만 가능 |
| 한글이 깨져서 발행됨 | 워크플로우를 API로 실행할 때 유니코드 이스케이프를 손으로 만들다 오타 | **입력값에 한글을 그대로** 넣는다 |
| 리호스팅이 무효가 됨 | 재빌드가 끝나기 전에 실행 | ①이 끝난 걸 로그로 확인하고 ③ 실행 |
| 브랜치 push 거부 | squash 머지로 히스토리가 갈라짐 | `git fetch origin main && git checkout -B <브랜치> origin/main` 후 작업 |

## 6. 컴플라이언스 (절대 어기지 않는 것)

- 제휴 글에는 **광고표시 문구를 첫 부분에** 넣는다 (발행 워크플로우가 자동 처리)
- 제휴 링크는 전부 `rel="nofollow sponsored noopener"`
- **가격·할인·쿠폰을 지어내지 않는다.** 확인 필요하면 `(확인 후 기입)`
- 금지어: 최고·무조건·100%·완벽·유일·강력추천·초특가
- **지어낸 1인칭 경험을 쓰지 않는다.** 운영자의 실제 경험이 아니면 독자를 향한 서술로
- 건강 주제는 **진료 우선**을 명시하고, 제품이 치료를 대신하는 것처럼 쓰지 않는다
