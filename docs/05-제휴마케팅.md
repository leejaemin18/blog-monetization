# Day 6+ — 제휴마케팅 수익화 (5강)

즉시 수익화가 가능한 핵심 파트입니다. 애드센스 승인과 무관하게 시작할 수 있습니다.

> 🚨 이 강의에는 **정지 사유가 되는 기법이 그대로 등장합니다.**
> 반드시 [`90-정책-준수-가이드.md`](90-정책-준수-가이드.md)를 먼저 읽으세요.

---

## 1. 수익 구조

```
콘텐츠 → 전용 제휴링크 클릭 → 유효시간 내 구매 → 판매액·상품 조건에 따라 수수료 정산
```

핵심: **상품·독자 의도와 맞는 링크만** 사용. 무관한 노출은 정책 위반입니다.

## 2. 플랫폼 선택

| 플랫폼 | 대상 | 수수료 | 비고 |
|---|---|---|---|
| **쿠팡 파트너스** | 쿠팡 전 상품 | 별도 정함 없으면 3% | 상품 다양, 초보 진입 쉬움 |
| **네이버 쇼핑 커넥트** | 스마트스토어 등록 상품 | 판매자가 상품별 설정 | 네이버 노출 강점 |
| Trip.com Partners | 항공·호텔·렌터카 | 강의 7% 주장(⚠️재확인) | 할인코드 콘텐츠 |
| iHerb Affiliates | 영양제·건강 | ⚠️재확인 | YMYL 주의 |
| 마이리얼트립 / AliExpress | 여행 / 해외직구 | ⚠️재확인 | |

각 프로그램의 현재 조건은 [`../data/offers.csv`](../data/offers.csv)에서 관리합니다.

### 쿠팡 파트너스 가입 (14단계)
[`../checklists/쿠팡파트너스-가입.md`](../checklists/쿠팡파트너스-가입.md) 참고. 핵심만:
1. `partners.coupang.com` 공식 도메인 확인 → 가입
2. 회원 유형(개인/사업자) — 임의 추정 말고 화면·세무상태로 확인
3. 실명·정산계좌·증빙 (민감정보는 공식 화면에만)
4. **홍보 미디어 등록** — 실제 광고 노출할 모든 채널 URL
5. 상품 링크 생성 → 공식 링크 그대로 사용
6. 게시물에 **광고 표시 문구** (제목/첫 부분)
7. 미디어 심사 대응 (광고표시+링크가 함께 보이는 화면 캡처)

## 3. 키워드 전략 — 검색량이 아니라 구매 의도

강의의 핵심 통찰: **검색량이 작아도 구매 직전 단계의 키워드**가 전환이 높다.

```
넓음  상품명            "식기세척기"              검색량 ↑ 구매의도 분산
  │   정확한 상품명      "쿠쿠 14인용 식기세척기"
  │   모델번호          "ABC-1234 후기"          ★ 구매 직전
  │   구매 수정어        "ABC-1234 최저가/쿠폰/설치"
좁음  시점·지역         "2026년 8월 일본 항공 할인코드"
```

### 키워드 발굴 11단계
1. 씨앗 상품 선택 (홍보 가능·재고 확인)
2. 정확한 상품명 (브랜드 + 제품명)
3. 상세페이지에서 **모델번호** 수집
4. 자동완성·연관검색어 (설치/후기/소음 등)
5. 구매 수정어 조합 (최저가·할인·쿠폰·비교·사용법)
6. 시점·지역 결합 (연·월·시즌·여행지)
7. 검색량 확인 (도구, 보조 지표일 뿐)
8. SERP 확인 (상위 결과 유형·최신성)
9. 제휴 가능성 (연결할 공식 상품·수수료 확인)
10. 콘텐츠 각도 (비교표/설치법/문제해결/FAQ)
11. **점수화** → `python3 tools/kwscore.py`

점수 기준: 구매의도 · 상품 관련성 · 콘텐츠 차별화 · 경쟁(역점수) · 정책 안전성
→ 상세 방법: [`06-수익화-글쓰기.md`](06-수익화-글쓰기.md) 및 `data/keywords.csv`

## 5. 외부 유입 (신중히)

신규 워드프레스 글은 바로 상위 노출되지 않으므로 외부 채널로 유입을 만든다는 전략.

| 채널 | 방식 |
|---|---|
| 네이버 지식인 | 관련 질문에 **완결된 답변** 먼저, 추가 자료로 링크 |
| 네이버 카페 | 규정 내에서 모델명·비교 정보 |
| 네이버 블로그 | 같은 주제를 **네이버 독자용으로 재작성** (복제 금지) |

> 🚫 자작 질문·도배·짧은 홍보 답변·무관 링크는 **플랫폼 정책 위반**입니다.
> "전단지처럼 무차별 배포"하지 말고, 실제로 도움 되는 답변만 소량 수동으로.

## 6. AI 글쓰기 (사람 검수 필수)

강사는 벤치마크 블로그 톤을 학습시켜 초안을 만드는 방식을 소개하며
"저작권 문제 전혀 없다"고 하지만 — **이는 과도한 단정입니다.**

AI 활용 10단계 (사실·독창성·저작권·광고표시는 사람이 최종 통제):
1. 참고자료 수집 (공식 사양·가격·확인일·직접 경험)
2. 벤치마크 **구조만** 분석 (문장·표현 복제 금지)
3. AI 초안 (제목·독자·검색의도·필수사실·금지표현·광고표시를 프롬프트에 명시)
4. **사실 검증** (수치·모델명·수수료를 공식 화면과 대조)
5. 독창성 편집 (본인 비교 기준·경험 추가)
6. CTA·링크 (강제·기만·보상형 클릭 금지)
7. AI 이미지 (실존 상표·인물·사양 왜곡 점검)
8. 공식 화면/이미지 (필요 최소 인용 + 출처, 또는 미디어킷)
9. 썸네일 (상업 이용 라이선스 확인, 허위 할인·만료 쿠폰·무단 로고 금지)
10. 최종 검수 (소비자 오인·사실성·권리·광고표시 중심)

## 7. 실행량

강사: 하루 5~10개 콘텐츠/외부유입, 1~2시간(빠른 성과는 4시간).
> ⚠️ **양보다 관련성·독창성·정책 준수가 우선.** 소규모 루틴으로 시작해 성과를 측정한 뒤 확대하세요.
> 무리한 대량 발행은 스팸 위험 + 품질 저하입니다.
