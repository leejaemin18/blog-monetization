# 브랜드킷 — 집사의 발견

세컨 블로그(반려동물) 디자인·꾸미기 세트입니다.
**GeneratePress 테마 기준**(강의 예시와 동일 계열). 색상·폰트·메뉴·로고 브리프를 여기서 복붙해 세팅하세요.

---

## 1. 정체성

| 항목 | 값 |
|---|---|
| 이름 | **집사의 발견** |
| 태그라인(대표) | **까다로운 집사가 직접 고른 반려템** |
| 태그라인(후보) | "우리 아이한테 진짜 좋은 걸 발견하다" / "사기 전에 들르는 집사의 리뷰" |
| 한 줄 소개 | 강아지·고양이 용품을 직접 따져보고, 살 만한 것만 골라 알려주는 리뷰 블로그 |
| 톤 | 솔직·꼼꼼·따뜻함. 광고가 아니라 "먼저 써보고 골라주는 친구" 느낌 |

## 2. 색상 팔레트 (HEX)

따뜻하고 신뢰감 있는 톤. GeneratePress **모양 → 색상**에 그대로 입력하세요.

| 용도 | 색상 | HEX |
|---|---|---|
| 메인(헤더·버튼) | 따뜻한 코랄 | `#E8825A` |
| 서브(링크·포인트) | 틸 그린 | `#2F9C95` |
| 본문 텍스트 | 웜 차콜 | `#33302B` |
| 배경 | 아이보리 | `#FFFCF7` |
| 보조/보더 | 연한 베이지 | `#EAE3D8` |
| 버튼 hover | 진한 코랄 | `#D96C43` |

> 링크·"구매하러 가기" 버튼은 **틸(#2F9C95)** 또는 **코랄(#E8825A)** 하나로 통일. 두 색을 한 버튼에 섞지 말기.

## 3. 폰트

| 위치 | 폰트 | 비고 |
|---|---|---|
| 제목(H1~H3) | **Gmarket Sans** 또는 Cafe24 Ssurround | 둥글고 친근 |
| 본문 | **Noto Sans KR** | 가독성·무난 |

GeneratePress → **모양 → 서체**에서 Google Fonts의 `Noto Sans KR` 지정. 제목용 한글 폰트는 웹폰트 CSS로 추가.

## 5. 메뉴(카테고리) 구조

상단 메뉴 = 홈 + 4개 카테고리 + 소개.

```
홈 | 사료·간식 | 용품·위생 | 펫가전·리빙 | 집사 가이드 | 소개
```

| 메뉴 | 슬러그(영문 URL) | 다룰 것 |
|---|---|---|
| 사료·간식 | food | 사료·간식·영양제 (재구매 핵심) |
| 용품·위생 | goods | 모래·패드·장난감·미용도구 |
| 펫가전·리빙 | gadget | 자동급수기·자동화장실·펫드라이어 등 |
| 집사 가이드 | guide | 입양·훈련·건강 정보(신뢰 유입) |

## 6. 소개(About) 페이지 초안

```
안녕하세요, '집사의 발견'입니다.

강아지 둘, 고양이 하나와 함께 살면서 정말 많은 반려용품을 사봤어요.
좋은 것도 있었지만, 광고만 보고 샀다가 후회한 것도 많았고요.

그래서 이 블로그를 시작했어요.
직접 따져보고, 우리 아이들 반응까지 확인한 뒤,
"이건 살 만하다" 싶은 것만 솔직하게 골라 정리합니다.

- 장점만이 아니라 단점·주의할 점도 함께 적어요.
- 확인 안 된 정보는 넣지 않아요.
- 일부 글에는 제휴 링크가 포함되며, 구매 시 일정 수수료를 받을 수 있어요(광고는 각 글에 표시).

여러분과 반려동물의 하루가 조금 더 편해지길 바라요.
```

> ⚠️ 발행 전 사람이 확인: 실제 반려동물 구성(마릿수·종)에 맞게 문구 수정. 지어낸 경험담 그대로 쓰지 말 것.
