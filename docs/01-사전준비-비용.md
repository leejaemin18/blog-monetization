# Day 0 — 채널 전략 · 니치 · 예산 확정

제휴 수익화를 시작하기 전에 끝내야 하는 것들입니다. 여기서 대충 넘어가면 나중에
방향을 갈아엎게 됩니다.

> 애드센스 블로그는 이미 개설되어 승인 대기 중이며 *제이통관블로그 워드프레스 프로젝트*에서
> 관리합니다. 여기서 정하는 것은 **제휴 수익화 채널** 세팅입니다.

## 1. 예산 확정 (제일 먼저)

수익이 **0원인 달에도** 감당 가능한 금액인지 계산합니다.

| 항목 | 강의 기준 금액 | 주기 | 이 프로젝트 | 내 금액 |
|---|---|---|---|---|
| 도메인 | 20,000~25,000원 | 연 1회 | 이미 보유 시 0 | |
| 호스팅 서버 1대 | 31,900원 | 월 | 애드센스 블로그와 공유 가능 | |
| 블로그 추가 (서버당 최대 3개) | 4,000원 | 월 | 세컨/서드 블로그용 | |
| 키워드 도구 | 20,000~30,000원대 | 월 | 선택 | |

- **서브도메인은 0원** — 도메인 1개로 세컨·서드 블로그를 무료로 붙일 수 있음
- **네이버 블로그는 완전 무료** — 서버·도메인 없이 시작
- 즉, 애드센스 블로그 서버에 **월 4,000원만 추가**하면 세컨/서드 블로그 운영 가능
- 금액은 특정 업체 상품 조건이며 변동. 결제 전 현재 화면에서 재확인

→ `data/niche.yaml`의 `budget` 항목에 기록

## 2. 채널 전략

이 프로젝트에서 굴릴 수익 채널을 정합니다.

| 채널 | 플랫폼 | 수익원 | 우선순위 |
|---|---|---|---|
| 세컨 블로그 | 워드프레스(서브도메인) | 쿠팡 파트너스, 네이버 쇼핑커넥트 | **1순위** |
| 네이버 블로그 | 네이버 (무료) | 제휴링크 + 애드포스트 | **1순위** (병행) |
| 서드 블로그 | 워드프레스 | 다른 니치 제휴 | 2순위 (세컨 검증 후) |

> **세컨 블로그 + 네이버 블로그를 먼저** 병행하고, 세컨에서 실제 전환(수익)이 확인되면
> 서드 블로그로 확장합니다. 근거 없이 사이트 수만 늘리지 않습니다.

## 3. 니치(주제) 선정 — "팔 수 있는 것"에서 역산

제휴는 검색 상위 노출보다 **구매 의도**가 핵심입니다.

| 방향 | 예시 | 제휴처 |
|---|---|---|
| 할인코드·쿠폰 | 여행 예약 쿠폰, 항공·호텔·렌터카 | Trip.com, 마이리얼트립 |
| 제품 모델명 리뷰 | 가전 모델별 비교·설치 | 쿠팡 파트너스, 네이버 쇼핑커넥트 |
| 해외직구 | 영양제, 액세서리 | iHerb, AliExpress |

니치 선정 체크:
| 확인 | 질문 |
|---|---|
| ⬜ | 연결할 **공식 제휴 상품·링크**가 실제로 있는가 |
| ⬜ | **모델명·할인코드·시기/지역** 같은 구매의도 키워드가 나오는가 |
| ⬜ | 세컨/서드/네이버 블로그에 **서로 다른 니치**를 배분했는가 |
| ⬜ | 정책 위험(YMYL, 과장 광고 소지)이 낮은가 |

- 세컨: 예) 여행 할인쿠폰 · 네이버 블로그: 예) 가전 모델 리뷰 (겹치지 않게)
- 같은 글을 여러 채널에 복제하지 않음

## 4. 제휴 프로그램 준비

| 프로그램 | 준비물 | 문서 |
|---|---|---|
| 쿠팡 파트너스 | 쿠팡 계정, 정산계좌, 증빙, **미디어(채널) URL** | `checklists/쿠팡파트너스-가입.md` |
| 네이버 쇼핑커넥트 | 네이버 계정 | `docs/05-제휴마케팅.md` |
| 네이버 애드포스트 | 네이버 블로그 | `docs/07-네이버블로그-수익화.md` |

⚠️ 광고를 노출할 **모든 채널(세컨/서드/네이버 블로그)을 미디어로 등록**해야 합니다.
미등록 미디어 노출은 쿠팡 정책 위반입니다.
