# Day 0 — 사전 준비와 비용 확정

블로그를 만들기 전에 끝내야 하는 것들입니다. 여기서 대충 넘어가면 나중에 도메인을
바꾸거나 사이트를 갈아엎게 됩니다.

## 1. 예산 확정 (제일 먼저)

수익이 **0원인 달에도** 감당 가능한 금액인지 계산합니다.

| 항목 | 강의 기준 금액 | 주기 | 필수 | 내 금액 |
|---|---|---|---|---|
| 도메인 | 20,000~25,000원 | 연 1회 | ✅ | |
| 호스팅 서버 1대 | 31,900원 | 월 | ✅ | |
| 블로그 추가 (서버당 최대 3개) | 4,000원 | 월 | ⬜ | |
| 키워드 도구 | 20,000~30,000원대 | 월 | ⬜ | |
| ChatGPT Plus | 약 30,000원 | 월 | ⬜ | |

- **최소 구성**: 도메인 + 서버 1대 ≈ 첫 달 5만원대, 이후 월 3만원대
- **6개월치 고정비를 감당할 수 있는가?** 애드센스 승인만 2~4주, 검색 노출은 더 걸립니다.
- 금액은 특정 업체 상품 조건이며 변동됩니다. 결제 전 현재 화면에서 재확인하세요.

→ `data/niche.yaml`의 `budget` 항목에 기록

## 2. 주제(니치) 선정

**1번 블로그 = 애드센스용**, **2번 블로그 = 제휴마케팅용**으로 나뉘므로 주제도 둘 다 정합니다.

### 1번 블로그 (애드센스 승인용)
강의의 3원칙: **전문성 + 일관성 + 생소한 분야**

여기에 다음 두 가지를 추가로 걸러냅니다.
- **정책 위험이 낮은가** — 건강·재무·법률(YMYL)은 전문성 입증 부담이 큼
- **30개 이상 쓸 수 있는가** — 제목만 뽑는 게 아니라 실제로 유용한 내용을 채울 수 있어야 함

```
후보 예시 (강의에서 나온 것): 콘크리트, 암막커튼, 라벨프린터, 복합기 유지관리, CCTV 설치
```

| 확인 | 질문 |
|---|---|
| ⬜ | 내가 실제 경험했거나 조사할 수 있는 분야인가 |
| ⬜ | 카테고리 1개로 묶이는가 (승인 전까지 카테고리는 1개) |
| ⬜ | 유용한 글 30개를 쓸 소재가 있는가 |
| ⬜ | YMYL 주제가 아닌가 |

### 2번 블로그 (제휴마케팅용)
"팔 수 있는 것"에서 역산합니다.

| 방향 | 예시 | 제휴처 |
|---|---|---|
| 할인코드·쿠폰 | 여행 예약 쿠폰 | Trip.com, 마이리얼트립 |
| 제품 모델명 리뷰 | 가전 모델별 비교 | 쿠팡 파트너스 |
| 해외직구 | 영양제, 액세서리 | iHerb, AliExpress |

⚠️ 두 블로그는 **주제·독자·수익모델이 명확히 달라야** 합니다.
심사 회피 목적으로 나누는 게 아니라, 다른 사업으로 운영하는 겁니다.

## 3. 도메인 후보 정하기

- **`.com` / `.co.kr` / `.kr` 중에서만** (강의 기준). `.부산.kr` 같은 것 금지
- 블로그 주제와 일치시킬 것 (예: 워드프레스 블로그 → `wp-blog.co.kr`)
- 소문자만, 짧게, 오탈자 나기 어렵게
- **확장성**: 나중에 서브도메인으로 2·3번 블로그를 붙일 것이므로 너무 좁은 이름은 피함
  - `kimchi-recipe.com` (좁음) vs `foodguide.co.kr` (확장 가능)

### 도메인 구매 전 확인
- [ ] **연간 갱신비** (첫해 할인가와 갱신가가 다른 경우가 많음)
- [ ] 자동갱신 설정 여부
- [ ] 소유권·이전 잠금 조건
- [ ] 상표권 침해 소지 (브랜드명 포함 금지)

## 5. 개인정보 입력 시 주의

가입 과정에서 실명·주소·계좌·신분증을 요구받습니다.
- **공식 도메인인지 반드시 확인** (검색 광고로 노출되는 유사 도메인 주의)
  - 쿠팡 파트너스 정식: `partners.coupang.com`
- 민감정보는 **공식 업로드 화면 외 어디에도 전송하지 않음**
- 애드센스 지급 주소는 **핀번호 우편을 실제로 받을 수 있는 주소**
  (수익 10달러 초과 시 우편 발송 → 핀 입력 필요)
