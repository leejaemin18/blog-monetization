# [참고] 워드프레스 블로그 만들기·설정 (1·2·3강 요약)

> 이 문서는 **참고용**입니다. 1·2·3강의 목적은 "블로그를 만들고 설정하는 법을 익히는 것"이며,
> 애드센스 기반 블로그 자체는 *제이통관블로그 워드프레스 프로젝트*에서 별도로 관리합니다.
>
> 세컨·서드 블로그를 만들 때(4강) 이 문서의 **Part B(세팅)**를 그대로 재사용합니다.

세부 원문이 필요하면 통합요약을 보세요 → [`00-강의-통합요약.md`](00-강의-통합요약.md)

---

## Part A — 워드프레스 개설 (1강)

1. **호스팅 가입** — 구글/카카오/네이버/이메일. 약관·주소·전화 등록
   - ⚠️ 공식 도메인 확인 (검색 광고의 유사 사이트 주의)
2. **도메인 구매** — `.com`/`.co.kr`/`.kr` 중, 소문자, 주제와 일치
   - 📝 갱신비·자동갱신·이전 잠금 확인
3. **워드프레스 생성** — 블로그명, 관리자 ID/강한 PW(별도 저장), 서버 결제 → 5~10분 대기
4. **로그인·초기 연결** — `/wp-admin` 로그인 → 북마크 → 테마 자동 설치 → 알팩 카카오 로그인

## Part B — 최적화 세팅 (2강) ★ 세컨·서드 블로그에서 재사용

**이 순서대로**:

1. **테마**: GeneratePress 설치·활성화 → 미사용 테마 삭제
2. **카테고리**: 주제별 + 짧은 영문 슬러그
   - 애드센스용은 승인 전까지 1개 / **제휴용은 여러 개 OK**
3. **메뉴**: 외모 → 메뉴 → Header Menu 생성 → 카테고리 추가
4. **파비콘**: ChatGPT 생성 → 설정 → 일반 → 사이트 아이콘 → 정사각형, 대체텍스트 입력
5. **사이트 제목·태그라인**
6. **알팩**: 빠른 버튼 / Header & Footer / Seen Analytics 활성화
7. **Rank Math**: 계정 연결 → 시작 마법사 (사이트맵·404·리디렉션 체크, **Content AI 등 유료 체크 해제**)
8. **첫 글 1개 발행** (사이트맵은 글이 있어야 생성됨)
9. **검색엔진 등록 4곳**:

| 검색엔진 | 핵심 |
|---|---|
| 네이버 서치어드바이저 | HTML 태그 인증 → 사이트맵 + RSS 제출. 반드시 `https://` |
| 구글 서치콘솔 | Rank Math 연결 시 자동 등록 많음. 사이트맵 + URL 검사 |
| Bing 웹마스터 | 메타 태그 인증 → 사이트맵 |
| Daum 검색등록 | PIN 코드 + robots.txt |

> 사이트맵: `https://내도메인/sitemap_index.xml` · RSS: `https://내도메인/feed`

## Part C — 애드센스 승인 (3강) — 이 저장소에서는 참고만

> 실제 애드센스 블로그 운영은 *제이통관블로그 워드프레스 프로젝트*에서 진행합니다.
> 여기서는 개념만 기록합니다.

- 주제 3원칙: 전문성 · 일관성 · 생소한 분야 (+ YMYL 회피, 실제로 유용한 30개 가능한지)
- 카테고리는 승인 전까지 1개
- 유용한 글 10개 발행 + 10개 예약(날짜·시간 분산)
- 애드센스 가입 → 지급정보(핀 수령 실주소) → 코드/ads.txt → 검토 요청
- 거절 대부분은 "가치 낮은 콘텐츠" → 품질 보강 후 재검토
- ⚠️ "10+10 발행 공식", "승인율 99%"는 근거 없음. 공식 기준은 **독창적·유용한 콘텐츠**

## 트러블슈팅 (세컨·서드에서도 동일)

| 증상 | 해결 |
|---|---|
| 사이트맵 "찾을 수 없음" | 글 1개 발행 후 재시도 |
| 등록/반영 안 됨 | 호스팅 콘솔 → CloudFront 캐시 삭제 |
| Rank Math에 사이트맵 안 뜸 | 사이트맵 모듈 활성화 |
| 소유권 확인 실패 | 헤더 코드 위치·저장 확인 |

**대부분의 워드프레스 반영 지연은 캐시 문제입니다.**
