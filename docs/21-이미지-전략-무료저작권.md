# 이미지 전략 + 무료·저작권 걱정 없는 사진 소스

제휴 블로그에서 이미지는 **상위노출(체류·품질)과 저작권 리스크**를 동시에 좌우합니다.
"어디서 안전하게 가져오나 / 어떻게 배치하나 / 뭘 쓰면 안 되나"를 한 문서로 정리했습니다.

> 조사일 2026-07. 라이선스·약관은 수시로 바뀌므로 **다운로드 시점에 각 사이트 라이선스를 재확인**하고
> 캡처해 두세요. ([`90-정책-준수-가이드.md`](90-정책-준수-가이드.md) 3번 저작권과 함께 보기)

---

## 0. 큰 원칙 3가지

1. **"무료"와 "상업적 이용 가능"과 "출처표시 불필요"는 각각 다른 조건.** 셋 다 만족하는지 확인.
2. **저작권과 상표권은 별개.** 사진은 저작권 문제가 없어도, **브랜드 로고·상표·특정 인물·건물**은
   따로 권리가 있음. 무료 사진 사이트에서 받았어도 그 안에 로고/사람 얼굴이 있으면 상업적 사용 제한.
3. **가장 안전한 순서**: ① 직접 촬영·제작 → ② 공식 미디어킷/제휴사 제공 이미지 → ③ 상업용 라이선스 확인된 무료 스톡 → ④ 검수한 AI 생성. **타인 상세페이지 캡처·브랜드 로고 무단 사용은 회피.**

무료 스톡보다 **직접 만든 그래픽**이 저작권상 가장 안전하고 상위노출에도 유리(원본성).

| 도구 | URL | 주의 |
|---|---|---|
| **Canva** | https://canva.com | 무료 요소만 쓰면 상업 가능. **Pro 전용 요소·프리미엄 사진**은 조건 다름 |
| **미리캔버스** | https://miricanvas.com | 한국형 템플릿. **상업적 이용 범위·소재 제한을 다운로드 시점에 확인** |
| **Figma** | https://figma.com | 정교한 배너·표 |

> ⚠️ 강의(5강)의 "미리캔버스/AI 이미지는 무료니까 상업 이용도 자유"는 **틀림**.
> 템플릿 안의 폰트·사진·요소가 각각 라이선스가 다를 수 있음. **다운로드 시점 조건을 캡처 보관.**

## 5. 제휴 상품 이미지 (쿠팡·Trip.com 등)

| 소스 | 사용 가능? |
|---|---|
| 쿠팡 **상품 대표이미지(썸네일)** | ✅ 파트너스 활동 범위 내 (위젯/딥링크 포함) |
| 쿠팡 **상세페이지 이미지·상품평 사진** | ❌ 저작권 (판매자/구매자 소유) |
| Trip.com 등 **공식 미디어킷/배너** | ✅ 제공 범위 내 |
| 공식 홈페이지 **화면 캡처** | ⚠️ 인용 요건 필요(출처·최소범위·목적). "여러 장 캡처하면 안 걸림"은 근거 없음 |

> 강의(5·6강)의 "공식 홈페이지 여러 장 캡처" 방식은 **저작권 회색지대**. 최소 인용+출처, 또는
> 공식 미디어킷/직접 제작으로 대체하세요.

## 6. 브랜드 로고 — 트립닷컴형 쿠폰 사이트가 특히 조심할 부분

쿠폰 소개 사이트는 브랜드 로고를 카드에 많이 씁니다. 하지만:
- 로고는 **저작권 + 상표권** 이중 보호. 무단 사용 시 상표권·부정경쟁 이슈 가능
- "쿠폰 정보를 소개"하는 **명목상 지시적 사용(nominative use)**은 여지가 있으나,
  **브랜드가 후원/보증한다는 오인**을 주면 안 됨
- **안전책**:
  1. 로고 대신 **직접 만든 텍스트 카드**("트립닷컴 렌터카 쿠폰")나 아이콘 사용
  2. 제휴사가 **공식 배너·미디어킷**을 주면 그 범위 내에서
  3. 로고를 쓸 경우 크기·맥락을 정보 전달 최소 범위로, 보증 오인 방지 문구

## 7. 이미지 배치 규칙 (상위노출용, 20번 문서 요약)

- 상위 글 평균 **6~13장**, **300~500자마다 1장**
- 유사·중복 이미지 금지 (저품질 신호)
- 썸네일 텍스트는 짧게("1+1", "무소음"), 상품 중앙 또렷, 정사각 1000×1000
- **파일명·alt에 핵심 키워드** (이미지 SEO)
- 네이버=직접촬영 위주 + 텍스트 링크 분리 / 워드프레스=위젯·배너 병용
- 2026 D.I.A: **1분+ 자체 영상/클립**에 가산점

## 8. 다운로드할 때 남길 기록 (분쟁 대비)

각 이미지마다 `data/` 또는 별도 시트에:
```
파일명 | 출처사이트 | URL | 라이선스명 | 상업이용 | 출처표시필요 | 다운로드일 | 캡처보관
```
→ 나중에 "이 사진 어디서 받았어?" 소명 가능. 라이선스 페이지를 캡처해 함께 보관.

## 한눈 요약 (제휴 블로그 이미지 결정 트리)

```
제품 사진이 필요하다
 ├─ 내가 실물 있음 → 직접 촬영 (최선)
 ├─ 쿠팡 상품 → 대표 썸네일/위젯 (상세페이지·리뷰사진 X)
 ├─ 분위기/배경 컷 → Unsplash·Pexels·Pixabay (인물·로고 없는 컷)
 ├─ 표·썸네일·카드 → Canva/미리캔버스 직접 제작 (라이선스 확인)
 └─ 브랜드 로고 → 가급적 회피, 필요시 공식 미디어킷·오인방지
```
