# 정책 준수 가이드 (가장 먼저 읽을 문서)

수익보다 먼저 지켜야 하는 것들입니다. 여기 있는 항목을 어기면
**계정 정지 · 수익 몰수 · 표시광고법 제재**로 이어질 수 있고, 그때는 그동안 쓴 글이 전부 무의미해집니다.

강의(특히 5강)에는 강사 본인이 "과거에 이렇게 해서 일 250~300만원을 벌었지만 정지당했다"고
설명한 기법들이 그대로 등장합니다. **설명은 참고하되, 실행은 하지 마세요.**

## 1. 경제적 이해관계 공개 (공정거래위원회 추천·보증 심사지침)

근거: https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000280130

제휴 링크가 들어간 **모든 게시물**에 수수료를 받는다는 사실을 표시해야 합니다.

### 표시 위치
| 판정 | 위치 |
|---|---|
| ✅ 적합 | 제목, 또는 본문 **첫 부분** (본문과 시각적으로 구분되게) |
| ❌ 부적합 | 본문 중간, 글 맨 끝, 댓글, "더보기" 뒤에 숨김 |

### 표시 문구
| 판정 | 예시 |
|---|---|
| ✅ | `이 글에는 제휴 링크가 포함되어 있으며, 링크를 통해 구매하시면 작성자가 일정액의 수수료를 받습니다.` |
| ✅ | `쿠팡 파트너스 활동의 일환으로 이에 따른 일정액의 수수료를 제공받습니다.` |
| ❌ | `체험 후기` / `홍보성 글` / `소정의 원고료` / `#광고` 만 단독 표기 |
| ❌ | 영어·해시태그만으로 표기 (`#ad`, `#sponsored`) |

→ 즉시 쓸 수 있는 문구: [`../templates/광고표시-문구.md`](../templates/광고표시-문구.md)
→ 자동 검사: `python3 tools/compliance.py 내글.md`

### AI 가상인물
AI가 만든 가상의 소비자·전문가가 상품을 추천하는 형태라면,
**게시물 첫 부분 또는 등장 지점 근처에 AI 가상인물임을 표시**해야 합니다.

### 허위 후기 금지
사용하지 않은 상품을 사용한 것처럼 쓰면 기만광고입니다.
글 안에서 다음 셋을 **명확히 구분**하세요.
- 내가 직접 경험한 것
- 공식 사양·공식 발표 (출처 URL + 확인일 기재)
- 제3자 후기 인용 (출처 명시)

## 2. 쿠팡 파트너스 운영정책 — 금지행위

근거: https://partners.coupang.com/#help/operating-policy

| 위험도 | 금지 행동 | 안전한 대안 |
|---|---|---|
| 🔴 매우높음 | 목차·더보기·콘텐츠 잠금 해제를 가장해 쿠팡으로 강제 이동 | 명시적인 제휴 버튼 + 정상 콘텐츠 제공 |
| 🔴 매우높음 | 동의 없는 메일·메신저·SMS로 링크 배포 | 동의 기반 채널만 사용 |
| 🔴 높음 | "도와주세요", "일단 클릭" 등 무의미한 클릭 유도 | 링크 도착지에서 무엇을 확인할 수 있는지 사실대로 설명 |
| 🔴 높음 | 파트너 코드·링크 형태·갱신주기 임의 변경 | 파트너스가 생성한 공식 링크 그대로 사용 |
| 🔴 높음 | 등록하지 않은 채널(미디어)에서 광고 노출 | 실제 노출하는 **모든** 채널을 미디어로 등록 |
| 🔴 높음 | 본문과 무관한 인기 브랜드·상품명 삽입 | 검색의도 ─ 본문 ─ 상품을 일치시킴 |
| 🟡 중~높음 | 노출수·클릭수·CTR·관련 그래프를 외부에 공개 | 수입 정보만 정책 범위 내 공개 |

### 정산 관련 사실
- 수수료: 별도 정함이 없으면 **3%** (상품·카테고리별 변동, 제외상품 있음)
- 월 지급 상한: 별도 정함이 없으면 **월 3,000만원**.
  초과분은 "이월되거나 지급되지 않음" — 강의의 "무조건 날아간다"는 표현은 과장입니다.
- 월 중 가입/탈퇴 시 일할계산
- 지급: 월 매출 → 익월 25일 내역 → 익익월 15일 지급. 1만원 이하 이월

> ⚠️ 강의의 "링크 방문 후 **24시간** 내 다른 상품 구매도 수익 인정"은 공개 운영정책에서
> 확인되지 않았습니다. 실제 링크 생성 화면과 최신 도움말에서 직접 확인하고 캡처해 두세요.

## 3. 저작권 · 상표

근거: https://www.law.go.kr/법령/저작권법/제28조 (공표된 저작물의 인용)

### 강의의 위험한 주장과 교정

| 강의 주장 | 문제 | 실제로 해야 할 것 |
|---|---|---|
| "블로그 말투를 학습시킨 거라 저작권 문제 전혀 없음" | 표현 복제·약관·부정경쟁 쟁점이 남음 | **아이디어와 구조만** 참고. 고유 문장·사진·표는 복제 금지 |
| "공식 홈페이지를 여러 장 캡처하면 다 다른 이미지라 탐지 불가" | 탐지 여부와 권리 유무는 무관 | 필요 최소 범위 인용 + 출처 표시, 또는 공식 미디어킷·라이선스 확보 |
| "미리캔버스/AI 이미지는 무료니까 상업 이용도 자유" | 서비스 약관과 소재 라이선스는 별개 | 다운로드 시점의 **상업 이용 범위**를 확인하고 기록 보관 |

### 이미지 우선순위
1. 직접 촬영·직접 제작
2. 브랜드가 공식 제공하는 미디어킷
3. 상업 이용 라이선스가 확인된 템플릿/스톡
4. 검수를 거친 AI 생성 이미지 (실존 상표·인물·제품 사양 왜곡 없는지 확인)
5. ~~공식 홈페이지 무단 캡처~~ ← 마지막 수단이며, 인용 요건을 갖춰야 함

## 4. 외부 유입 채널 규정

| 채널 | 하면 되는 것 | 하면 안 되는 것 |
|---|---|---|
| 네이버 지식인 | 질문에 **완결된 답변**을 먼저 주고, 추가 자료로 링크 | 자작 질문·자문자답, 짧은 홍보 답변, 도배 |
| 네이버 카페 | 카페 규정 내에서 모델명·비교 정보 제공 | 홍보 금지 카페에 링크, 중복 게시 |
| 네이버 블로그 | 같은 사실을 **네이버 독자용으로 재작성** | 워드프레스 원문 그대로 복제 |
| Threads/SNS | 팁·업데이트 + 프로필 링크 | 반복 링크 도배, 낚시 문구, 미등록 미디어 노출 |
| YouTube | 설명란에 관련 링크 + 명확한 광고 표시 | 영상/음원/상표 권리 미확인 |

**공통 원칙**: 한 원문을 여러 매체에 그대로 붙여넣는 "돌려치기"는
플랫폼 스팸 정책과 검색 품질 양쪽에서 불리합니다. 매체별로 다시 씁니다.

## 5. 애드센스

근거: https://support.google.com/adsense/answer/48182

- AI로 대량 생성한 유사 콘텐츠를 검색 순위 조작 목적으로 확장하는 것은 스팸 정책 위반
- 건강·재무·법률 주제(YMYL)는 전문성·출처·면책 범위를 강화해야 함
- 지급 주소·수취인·세금 정보는 **실제 정보**로 입력 (핀번호 우편 수령 가능한 주소)
- 개인정보처리방침은 **실제 수집하는 데이터와 일치**해야 함 (AI 초안 그대로 게시 금지)
- 거절 사유는 추측하지 말고 계정 메시지와 공식 정책 문서를 확인

## 6. 발행 전 필수 확인 6가지

매 글마다. 하나라도 ❌면 발행하지 않습니다.

- [ ] 광고 표시 문구가 **제목 또는 첫 문단**에 있는가
- [ ] 제휴 링크가 공식 생성 링크이고, 클릭 시 **의도한 페이지**로 가는가 (모바일 포함)
- [ ] 쿠폰 금액·유효기간·제외조건을 **공식 출처에서 오늘 확인**했는가 (URL + 확인일 기록)
- [ ] 본문의 모든 이미지가 권리 확인된 것인가
- [ ] 경험하지 않은 것을 경험한 것처럼 쓴 문장이 없는가
- [ ] 본문 주제와 무관한 상품·브랜드 링크가 없는가

자동 검사:
```bash
python3 tools/compliance.py drafts/내-글.md
```
