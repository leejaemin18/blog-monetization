# 프레스런 무료강의 1~6강 통합 요약

원본 학습노트 6종(각 강의별 자막 전체를 분 단위로 재구성)을 한 장으로 압축한 문서입니다.
세부 실행은 각 강의별 문서를 참고하세요.

> **이 프로젝트의 우선순위**
> - **1·2·3강 = 참고** — "블로그 만들고 설정하는 법"만 익힘. 애드센스 블로그 자체는
>   승인 대기 중이며 *제이통관블로그 워드프레스 프로젝트*에서 별도 관리
>   → [`10-블로그-만들기-참고.md`](10-블로그-만들기-참고.md)
> - **4·5·6강 = 핵심** — 세컨/서드 블로그 + 네이버 블로그로 **쿠팡 파트너스 · 네이버
>   쇼핑커넥트** 제휴 수익화. 아래 4강부터가 실제 작업입니다.

## 전체 흐름

```
[1강] 워드프레스 개설          ─ 서버 임대 + 도메인 구매 + WP 원클릭 설치
   ↓
[2강] 최적화 세팅 (1회성)      ─ 테마·카테고리·메뉴·파비콘·SEO·검색엔진 등록
   ↓
[3강] 애드센스 승인            ─ 단일 틈새 주제로 글 20개 (10개 발행 + 10개 예약) → 심사 요청
   ↓                              심사 2~4주 소요 → 이 기간에 1번 블로그는 건드리지 않음
[4강] 2번째 블로그 개설        ─ 서브도메인 활용, 제휴마케팅 전용 사이트
   ↓
[5강] 제휴마케팅 수익화        ─ 쿠팡 파트너스 / 네이버 쇼핑 커넥트 / Trip.com 등
   ↓
[6강] 수익화 글쓰기            ─ 할인코드 테이블 + 키워드 조합 + 메타설명 + 수집 요청
```

## 강의별 핵심 (한 줄 요약)

| 강 | 제목 | 핵심 한 줄 | 소요 |
|---|---|---|---|
| 1 | 2026년 워드프레스 무료강의 리뉴얼 | 서버는 사는 게 아니라 **임대**한다. 도메인 1개 + 서버 1대로 시작 | 16:09 |
| 2 | 30분만에 끝내는 최적화 블로그 세팅 | GeneratePress + Rank Math + 4개 검색엔진 등록. **딱 한 번만** 하는 작업 | 29:34 |
| 3 | 구글 애드센스 승인 쉽게 받는 방법 | **전문성 · 일관성 · 생소한 분야** 3원칙. 카테고리는 승인 전까지 1개 | 24:58 |
| 4 | 제휴마케팅 전 2번째 블로그 개설 | 서브도메인은 **무료**. 심사 중인 사이트에 머니 키워드를 섞지 않는다 | 29:03 |
| 5 | 제휴마케팅 즉시 수익화 | 상품명이 아니라 **모델명 · 할인코드 · 시기/지역** 키워드 | 40:43 |
| 6 | 10분만에 배우는 수익화 전략 글쓰기 | 공식 홈페이지의 **최신 쿠폰 정보**를 정확히 옮기는 것이 경쟁력 | 13:57 |

## 1강 — 워드프레스 개설

- **구글 블로그 3종**: 티스토리 / 블로그스팟 / 워드프레스 → 워드프레스 선택
- **수익 모델 2종**: 구글 애드센스(광고) + 제휴마케팅(판매 수수료)
- 도메인은 `.com` / `.co.kr` / `.kr` 중에서만. 블로그 주제와 일치시킬 것
- 워드프레스 관리자 주소(`/wp-admin`)를 **북마크**하고 ID/PW를 별도 보관
- ⚠️ 애드센스 68% 배분, 호스팅 월 3~4만원 등은 시점·상품별로 변동

## 2강 — 최적화 세팅 (블로그당 1회)

세팅 순서 (이 순서를 지키면 막히지 않음):

1. **테마**: GeneratePress 설치·활성화 → 미사용 기본 테마 삭제
2. **카테고리**: 주제별 생성 + 짧은 영문 슬러그
3. **메뉴**: 외모 → 메뉴 → Header Menu 생성 → 카테고리 추가
4. **파비콘**: 정사각형 이미지 → 설정 → 일반 → 사이트 아이콘. 대체텍스트 필수 입력
5. **사이트 제목·태그라인**
6. **분석/헤더 도구**: 방문자 통계, 헤더/푸터 코드 삽입 영역 활성화
7. **Rank Math**: 계정 연결 → 시작 마법사 → 사이트맵·404·리디렉션 모듈 체크
   - Content AI 등 유료 기능은 **체크 해제**
8. **검색엔진 등록 4곳**:
   - 네이버 서치어드바이저 → HTML 태그를 헤더에 삽입 → 사이트맵 + RSS 제출
   - 구글 서치콘솔 → Rank Math 연결 시 자동 등록되는 경우가 많음
   - Bing 웹마스터 도구 → 메타 태그 인증
   - Daum 검색등록 → PIN 코드 + robots.txt

> 사이트맵 경로: `https://내도메인/sitemap_index.xml` · RSS: `https://내도메인/feed`
> **글이 0개면 사이트맵이 생성되지 않습니다.** 글 1개 발행 후 제출하세요.

⚠️ "모든 외부 링크 nofollow"는 강사 설정이지 공식 권장이 아닙니다. 광고·후원 링크에는
`rel="sponsored"`, 신뢰할 수 없는 링크에는 `nofollow`를 쓰는 것이 구글 공식 안내에 가깝습니다.

## 3강 — 애드센스 승인

**주제 선정 3원칙** (강사 노하우, 공식 기준 아님):
1. 전문성 있는 주제
2. 일관성 있는 단일 카테고리
3. 생소한 분야 (경쟁이 적음)

**실행 공식** (강사 주장):
- ChatGPT로 조건에 맞는 제목 30개 생성
- 10개 **당일 발행** + 10개 **예약 발행** (날짜·시간 모두 다르게)
- 심사 기간(2~4주) 내내 하루 1개씩 올라가도록 배치
- 애드센스 가입 → 지급 정보(핀번호 수령 가능한 실주소) → 사이트 코드 + ads.txt → 검토 요청
- 거절 사유 대부분은 "가치가 별로 없는 콘텐츠" → 글 10개 추가 발행 + 10개 예약 후 재검토
- 개인정보처리방침 / DMCA 페이지 추가 (강사도 "카더라"로 명시)

**카테고리는 승인 전까지 반드시 1개.** 카테고리와 무관한 글을 쓰면 안 됩니다.

⚠️ "10+10 발행이 승인 공식"이라는 근거는 없습니다. 애드센스 공식 기준은 **독창적이고
유용한 콘텐츠**입니다. AI 초안을 그대로 대량 발행하는 것은 스팸 정책 위반 위험이 있습니다.

## 4강 — 2번째 블로그 (제휴 전용)

**왜 나누는가**: 애드센스 심사 중인 사이트에 머니 키워드(수익형 키워드)를 쓰면
주제가 희석되어 승인율이 떨어진다는 것이 강사 주장. → 제휴 글은 별도 사이트에 씁니다.

- **서브도메인은 추가 비용 0원** (`coupon.내도메인.co.kr`). 도메인 1개만 사면 무제한
- 서버 1대당 블로그 1개가 기본. 월 4,000원 추가 시 서버당 최대 3개
- 세팅은 2강과 동일한 순서를 반복 (2번째부터는 5분이면 끝남)
- **문제 대부분은 캐시 문제**. 사이트맵/RSS 등록이 안 되면 호스팅 콘솔에서 CloudFront 캐시 삭제
- 네이버 서치어드바이저 등록 시 반드시 `https://` (http 아님)

⚠️ 사이트가 늘면 업데이트·백업·정책 점검 비용도 같이 늘어납니다.
같은 글을 루트/서브도메인에 복제하지 마세요.

## 5강 — 제휴마케팅

**구조**: 콘텐츠 → 전용 제휴링크 클릭 → 유효시간 내 구매 → 수수료 정산

**쿠팡 파트너스**
- 별도 정함이 없으면 수수료 3% (상품·카테고리별 변동, 제외상품 존재)
- 월 지급 상한 3,000만원. 초과분은 **이월되거나 지급되지 않음**
- 정산: 월 매출 → 익월 25일 내역 확정 → 익익월 15일 지급. 1만원 이하 이월
- 광고를 노출할 **모든 채널을 미디어로 등록**해야 함 (미등록 미디어 노출 금지)
- 노출수·클릭수·CTR은 **외부 공개 금지** (수입 정보는 공개 가능)

**네이버 쇼핑 커넥트**
- 스마트스토어 판매자가 등록한 상품만 대상. 수수료는 판매자가 상품별로 설정

**키워드 전략** — 검색량보다 **구매 의도**:
```
상품명       →  "식기세척기"           (검색량 크지만 구매의도 분산)
정확한 상품명 →  "쿠쿠 14인용 식기세척기"
모델번호     →  "ABC-1234 후기"        ★ 검색량 작아도 구매 직전 단계
구매수정어    →  "ABC-1234 최저가/쿠폰/설치"
시점·지역    →  "2026년 8월 일본 항공 할인코드"
```

**외부 유입**: 신규 워드프레스 글은 바로 상위 노출되지 않으므로
네이버 블로그 / 카페 / 지식인에서 유입을 만든다는 전략.
→ 단, **자작 질문·도배·무관 링크는 플랫폼 정책 위반**. 실제로 도움 되는 답변만.

**🚫 강의에 나오지만 절대 따라하면 안 되는 것** (강사 본인도 정지 경험을 언급):
- 목차·버튼 클릭을 제휴 링크로 강제 연결
- 콘텐츠를 가리고 쿠팡 방문을 조건으로 해제하는 "더보기 광고"
- 무의미한 클릭 유도("도와주세요", "일단 눌러주세요")
- 파트너 코드·링크 임의 조작

## 6강 — 수익화 글쓰기 (실전)

할인코드 유형 글의 완성 순서:

1. 제휴 프로그램 가입 (예: Trip.com Partners) → 프로필·통화·수취 정보 입력
2. 카테고리별 **딥링크 생성** (항공권 / 호텔 / 렌터카 각각) → 단축 링크 → 리퍼럴 코드 확인
3. **공식 홈페이지에서 현재 유효한 쿠폰 코드·할인율·마감일 확인**
   - 경쟁 글들은 만료된 정보를 방치하는 경우가 많음 → 여기가 차별점
4. HTML 테이블 템플릿을 워드프레스 `/html` 블록에 삽입
5. **제목**: 핵심 키워드 + 동의어/연관어 3~5개를 자연스럽게 조합
   - `할인코드` ≈ `쿠폰` ≈ `특가` ≈ `프로모션` (동의어를 함께 담음)
   - 예: `Trip.com 렌터카 할인 코드 쿠폰 포함 2026년 7월 최신`
6. **메타설명**: ChatGPT로 초안 → 사실 확인 후 수정 → Rank Math 스니펫에 160자 내외
   - Rank Math **점수는 순위와 무관**. 집착하지 말 것
7. 썸네일 생성 → 대표 이미지 설정 (제목·대체텍스트 입력)
8. 발행 후 **네이버 서치어드바이저 → 웹페이지 수집 요청** (신규 사이트는 한 달간 매 글마다)
