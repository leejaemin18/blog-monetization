# 자동 글쓰기 프로그램 → 크롬 확장 타당성 검토

강의(1·5강)에 나오는 "결제하면 블로그 글을 자동으로 잘 써주는 프로그램"(알팩 프로 / Loword류)을
**크롬 확장프로그램으로 만들 수 있는지** 조사한 문서입니다.

> 조사일 2026-07. 기술 스택·API·정책은 변동됩니다. 실제 구현 전 재확인하세요.

---

## 결론 먼저

- **초안 생성 어시스턴트로는 충분히 가능하고 합리적입니다.** (권장 ✅)
  키워드/제목을 입력하면 우리 스타일 가이드에 맞는 **초안 + 광고표시 + 링크 자리**를 생성해
  워드프레스/네이버 에디터에 넣어주는 형태. **사람이 검수 후 발행.**
- **"완전 무인 자동 발행"은 권장하지 않습니다.** (⚠️ 위험)
  네이버는 자동 포스팅·매크로를 **약관으로 금지**하고 저품질/제재 위험이 큽니다. 워드프레스는
  기술적으로 가능하나(REST API), AI 대량 자동 발행은 스팸·품질 저하로 이어집니다.
- 실제로 시중 프로그램의 핵심 원리는 **① 상품 API로 이미지·제휴링크 자동 삽입 + ② LLM으로 SEO 초안 생성
  + ③ 자동 포스팅**입니다. 이 중 ①②는 확장으로 구현 가능, ③은 위험을 감수해야 합니다.
  (조사: 크몽/티스토리 자동화 사례 다수가 "AI 글은 검색엔 걸려도 **구매 전환은 약하다**"고 지적)

→ **우리 방향: ①②만 하는 "초안 어시스턴트" 확장 + 사람 발행.** 프로토타입 골격을 `extension/`에 넣었습니다.

## 1. 시중 프로그램이 하는 일 (원리)

| 단계 | 방식 |
|---|---|
| 상품 선정 | 쿠팡 API/키워드 도구로 고수익 상품·키워드 |
| 이미지·링크 | **쿠팡 파트너스 Open API**(딥링크 생성, HMAC-SHA256 인증)로 상품 이미지·수익링크 자동 |
| 글 생성 | Gemini/GPT 등 LLM으로 SEO 초안 |
| 발행 | 워드프레스 API / 매크로로 자동 포스팅, 예약 |

> 쿠팡은 실제 **Open API + 오픈소스 SDK(JS/TS)**, 심지어 상품정보 추출 **크롬 확장 예제**까지 존재
> → 확장으로 상품 이미지·딥링크를 다루는 것은 **선례가 있음**.

## 2. 크롬 확장으로 가능한가? — 아키텍처

가능합니다. Manifest V3 기준 구성:

```
┌─ 크롬 확장 (MV3) ─────────────────────────────┐
│  Side Panel/Popup (UI)  ─ 제목·키워드·니치 입력  │
│  Service Worker (background) ─ 메시지 라우팅     │
│  Content Script ─ 워드프레스/네이버 에디터에 삽입 │
└───────────────┬───────────────────────────────┘
                │ (API 키는 확장에 넣지 않음!)
                ▼
        Backend Proxy (내 서버) ── Claude API 호출
                                └─ (선택) 쿠팡 파트너스 API
```

**핵심 설계 결정: API 키를 확장에 넣지 말 것.**
- 확장 코드는 누구나 열어볼 수 있어 **Anthropic/쿠팡 API 키가 그대로 노출**됩니다.
- 반드시 **본인 서버(백엔드 프록시)**가 키를 쥐고 대신 호출. 확장은 프록시만 부릅니다.
- MV3는 **원격 코드 로딩 금지** → 로직은 확장에 내장, 비밀만 프록시로.

## 3. 글 생성 엔진 — Claude API

- 모델: **`claude-opus-5`** (Anthropic 최신·최상위. 한국어 품질 우수)
- 방식: Messages API (`client.messages.create`)
- 프록시에서 **우리 스타일 가이드를 system 프롬프트로** 주입 →
  말투/링크 1~3개/광고표시/이미지 자리/FAQ 구조를 지킨 초안 생성
  ([`../templates/제휴글-스타일가이드.md`](../templates/제휴글-스타일가이드.md))
- 생성 후 확장에서 `compliance.py`와 동일한 규칙을 재검사(선택)

> 참고: 강의의 "저작권 문제 전혀 없음"은 틀림. 벤치마크는 **구조만**, 문장 복제 금지.
> AI 초안은 **사람이 사실·링크·광고표시 최종 검수** 후 발행.

## 4. 제휴링크·이미지 — 쿠팡 파트너스 API (선택)

- 쿠팡 파트너스 **Open API**로 딥링크 생성·상품검색·이미지 URL 취득 가능
- 인증: HMAC-SHA256 서명(키를 프록시에 보관)
- ⚠️ 파트너스 승인·이용약관 준수 필요. 상품 **대표 썸네일**만 사용(상세페이지 이미지 금지)
- 이미지 저작권 규칙 → [`21-이미지-전략-무료저작권.md`](21-이미지-전략-무료저작권.md)

## 5. 발행 단계 — 여기서 갈림길

| 방식 | 가능성 | 위험 |
|---|---|---|
| **초안을 에디터에 삽입** (사람이 검수·발행) | ✅ 권장 | 낮음 |
| 워드프레스 REST API 자동 발행 | 가능 | AI 대량 발행 시 스팸·품질 |
| **네이버 블로그 자동 포스팅/매크로** | ❌ | **약관 위반·저품질·계정 제재** |

> 네이버는 공식 글쓰기 API가 없고 자동화에 강한 반봇 정책. **네이버는 손으로 붙여넣고 발행**하세요.
> 확장의 content script는 "초안을 에디터에 넣어주는" 데까지만.

## 6. 정책·리스크 요약

- 🚫 네이버 자동 포스팅/매크로 = 약관 위반
- 🚫 AI 초안 그대로 대량 발행 = 애드센스/검색 스팸 정책 위반, 저품질
- 🚫 API 키를 확장에 하드코딩 = 유출
- ✅ 사람이 광고표시·링크·사실을 최종 검수(휴먼 인 더 루프)
- ✅ 하루 소량, 품질 우선 → 강의의 "하루 5~10개 자동"보다 안전

## 7. 비용 (대략)

| 항목 | 대략 |
|---|---|
| Claude Opus 5 | 입력 $5 / 출력 $25 per 1M 토큰. 글 1편(초안 ~2000자≈3~4k 토큰 출력) ≈ 수십~백원대 |
| 프록시 서버 | 무료 티어(Cloudflare Workers/Vercel/작은 VPS)로 시작 가능 |
| 쿠팡 API | 무료(파트너스 승인 필요) |

> 비용은 모델·토큰·환율로 변동. 소량 테스트로 실측하세요.

## 8. 만들 것 vs 안 만들 것

**만든다 (프로토타입 `extension/`에 골격 포함)**
- 제목·키워드·니치 입력 UI
- 프록시 경유 Claude 호출 → 스타일 가이드 준수 초안
- 광고표시 문구 자동 삽입, 링크 **자리표시자**(사람이 실제 딥링크로 교체)
- 워드프레스/네이버 에디터에 초안 삽입(content script)

**안 만든다 (권장 안 함)**
- 네이버 자동 포스팅/매크로
- API 키를 확장에 내장
- 사람 검수 없는 무인 대량 발행

## 프로토타입

`extension/` 폴더에 **동작 가능한 최소 골격**을 넣었습니다.
- `extension/manifest.json` — MV3
- `extension/sidepanel.html` / `sidepanel.js` — 입력·생성·복사 UI
- `extension/background.js` — 프록시 호출
- `extension/content.js` — 에디터에 초안 삽입
- `extension/proxy/server.js` — **API 키를 쥐는 백엔드 예제**(Anthropic SDK, `claude-opus-5`)
- `extension/README.md` — 설치·실행법

> ⚠️ 이 골격은 **학습·검토용**입니다. 실제 사용 전 프록시 인증·요금·정책을 반드시 점검하세요.
> 자동 발행 기능은 의도적으로 넣지 않았습니다(초안 삽입까지만).
