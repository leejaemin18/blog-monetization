# Day 6+ — 수익화 글쓰기 실전 (6강)

할인코드 유형 글을 예시로 한 편을 완성하는 전 과정입니다.
쿠팡 상품 리뷰도 동일한 흐름을 씁니다.

---

## 예시: Trip.com 할인코드 글

### 1. 제휴 프로그램 가입
- Trip.com Partners 공식 페이지 → 가입
- 프로필: 이름, 전화(+82), 이메일, 사업 유형(없으면 개인→기타), 국가(KOREA)
- **결제 통화 USD**, 제휴 방식 = 광고(블로그)
  - ⚠️ "USD·Other 선택이 정답"은 강사 방식이지 공식 규칙이 아님. 본인 상황에 맞게

### 2. 딥링크 생성 (카테고리별)
대시보드 → 맞춤 링크 → Trip.com에서 **항공권/호텔/렌터카** 각 페이지 접속
→ 해당 URL 복사 → 제휴 링크 생성 → 단축 링크 → 복사
- 링크 클릭 시 **리퍼럴 코드가 붙는지 확인** (예: `9351294`)
- 출발지·도착지가 비어 있는 범용 페이지로 연결하는 게 좋음

### 3. 공식 쿠폰 정보 확인 ★ 차별점
구글에 "Trip.com 항공권 할인코드 2026년" → **공식 홈페이지**에서:
- 현재 유효한 **할인코드**
- **할인율** (예: 렌터카 최대 8%)
- **마감일** (예: 9월 30일)
- 신규 고객 혜택 (예: 최대 22,000원)

> **경쟁 글들은 만료된 정보를 방치**하는 경우가 많습니다. 최신·정확한 정보가 경쟁력입니다.
> 틀린 코드를 주면 독자가 이탈하고 검색 신뢰도도 떨어집니다.
> → 만료일은 `data/offers.csv`에 등록하고 `python3 tools/offers.py`로 감시

### 4. HTML 테이블 삽입
- 워드프레스 글 추가 → `/html` 입력 → HTML 편집 → 템플릿 붙여넣기
- 템플릿: [`../templates/할인코드-테이블.html`](../templates/할인코드-테이블.html)
- 제휴 URL·할인율·마감일·이미지를 **검증된 값으로** 교체
- ⚠️ AI가 만든 HTML은 링크 목적지·보안·모바일·접근성을 사람이 검수

### 5. 제목 — 동의어·연관어 조합
할인코드 ≈ 쿠폰 ≈ 특가 ≈ 프로모션 (같은 의도의 표현을 함께 담음)

```
Trip.com 렌터카 할인 코드 쿠폰 포함 2026년 7월 최신
└─핵심 키워드─┘ └상품┘ └─동의어─┘ └─시점(최신성)─┘
```

- 핵심 1개 + 관련 수식어 **3~5개** (많다고 좋은 게 아님)
- 본문에 없는 내용을 제목에 넣지 말 것 (항공권 글에 "후기"를 넣으면 불일치)
- 허위 최신성 금지 (지난 달인데 "최신"이라 쓰지 않기)

### 6. 메타설명 (Rank Math 스니펫)
```
[제목]을 토대로 메타설명 200자 내외로 작성해줘.  (ChatGPT)
→ 짧게 나오면: 1.5배 분량으로 더 작성해줘
```
- Rank Math → 스니펫 편집 → 붙여넣기 → **160자 내외로 조정**
- 포커스 키워드: 제목 앞부분
- ⚠️ **Rank Math 점수는 순위와 무관.** 100점이라고 노출이 잘 되는 게 아님. 집착 금지
- ⚠️ 메타설명 내용이 실제 페이지 내용과 일치해야 함

### 7. 썸네일 + 발행
```
[제목] 썸네일 만들어줘  (ChatGPT)
```
- 다운로드 → 대표 이미지 설정 → 제목·대체텍스트 입력
- 발행 전: `python3 tools/compliance.py drafts/글.md` + [`../checklists/발행전-체크리스트.md`](../checklists/발행전-체크리스트.md)
- 발행

### 8. 수집 요청
네이버 서치어드바이저 → 웹마스터 도구 → 요청 → **웹페이지 수집** → 발행 글 URL 제출
- 신규 사이트는 **약 한 달간** 매 글마다 수동 요청 (강사 권장, 필수는 아님)
- 한 달 후 네이버가 사이트를 인지하면 자동 수집

상위노출 글의 말투·링크·이미지 실전 규칙 → [`../templates/제휴글-스타일가이드.md`](../templates/제휴글-스타일가이드.md)

| 구간 | 원칙 | 주의 |
|---|---|---|
| 기획 | 검색의도 1개 결정 (정보형/비교형/구매형/문제해결형) | 검색량만으로 선택 금지 |
| 제목 | 핵심키워드 + 구체 혜택/상황 | 키워드 나열·허위 최신성 금지 |
| **광고 표시** | 제목 또는 첫 부분에 수수료 관계 명시 | 댓글/더보기 뒤 금지 |
| 도입 | 독자 문제 + 결론 미리보기 | 목차 클릭을 링크로 강제 금지 |
| 본문 | 가격·규격·설치·장단점을 표/소제목으로 | 근거 없는 TOP5 금지 |
| 경험 | 직접경험/공식사양/제3자후기 **분리** | 안 써보고 후기처럼 쓰면 부당광고 |
| 링크 | 관련 문맥에 전용링크, 목적지 일치 | 클릭 강요 금지 |
| CTA | "현재 판매가·적용 쿠폰 확인"처럼 사실 기반 | 없는 할인·과장 금지 |
| 이미지 | 권리 확인된 자료만 | 공식 캡처도 자동 자유이용 아님 |
| FAQ | 롱테일 질문 답변 | 정책·가격에 날짜 표시 |
| 마감 | 출처 URL + 확인일 + 개인차 고지 | 수익 보장 표현 금지 |
| 검수 | 사실·링크·광고표시·저작권·오탈자·모바일·플랫폼규정 | AI 생성 그대로 발행 금지 |

## 쿠팡 상품 글도 동일

Trip.com 자리에 쿠팡 상품을 넣으면 됩니다.
- 쿠팡에서 홍보할 상품 선택 → 파트너스 링크 생성 → 이미지 넣고 작업
- 광고 표시 문구 필수, 모델명 키워드 활용

## 벤치마킹 원칙

- 돈 버는 블로그의 **구조·다루는 키워드·누락된 정보**만 참고
- 🚫 문구·이미지·표를 **복제하지 않음** (저작권)
- "말투를 학습했으니 저작권 문제 없다"는 강사 주장은 틀림
