# Day 5+ — 두 번째 블로그(제휴 전용) 개설 (4강)

애드센스 심사가 진행되는 동안, 제휴마케팅 전용 블로그를 하나 더 만듭니다.

## 왜 나누는가

강사 주장: 애드센스 심사 중인 사이트에 **머니 키워드(수익형 키워드)**를 쓰면
주제가 희석되어 승인율이 떨어진다. → 제휴 글은 별도 사이트에 쓴다.

> ⚠️ "머니 키워드가 승인을 희석시킨다"는 공식 근거가 없습니다. 다만 **주제 일관성**이라는
> 원칙 자체는 합리적이고, 애드센스용/제휴용을 나누는 것은 관리상 이점이 있습니다.
> **심사 회피가 아니라, 독자·주제·수익모델이 다른 별도 사업으로** 운영하세요.

## 서브도메인 = 추가 비용 0원

- 메인 도메인 `wp-blog.co.kr`을 한 번 사면, 앞에 붙는 서브도메인은 **무제한 무료**
  - `coupon.wp-blog.co.kr`, `travel.wp-blog.co.kr` ...
- 새 메인 도메인을 또 사면 그건 별도 비용

⚠️ 등록비는 0원이지만 호스팅·DNS·SSL 비용과 제약은 존재합니다.

## 개설 순서

### 1. 서브도메인 추가
호스팅 콘솔 → 프로필 → 내 콘솔 관리 → 도메인 관리 → 내 도메인 클릭
→ 서브도메인 추가 → 이름 입력(예: `couponking`) → 추가하기

### 2. 블로그 추가 (멀티사이트)
- 서버 1대당 블로그 1개가 기본
- **월 4,000원 추가** 시 서버당 최대 3개까지
- 호스팅 관리 → 서버 → 워드프레스 관리 → "블로그를 추가하세요" → 부가서비스 결제
- 블로그 이름·ID·PW 입력 → 루트 도메인 연결에서 **추가한 서브도메인 선택** → 완료

> 블로그를 4개 이상 원하면 서버를 1대 더 사고(라이트 플랜) 멀티서비스를 추가 → 서버당 3개 = 최대 6개

### 3. 세팅 (2강 반복)
2번째부터는 5분이면 끝납니다. [`02-워드프레스-세팅.md`](02-워드프레스-세팅.md) Part B를 그대로:

1. 브릿지 테마 어시스턴트 비활성화·삭제
2. **사이트 제목** — 제휴 주제에 맞게 (예: "AI·여행·게임 할인쿠폰 모음")
3. 태그라인 · 파비콘 (ChatGPT)
4. Rank Math 시작 마법사 (유료 기능 체크 해제)
5. GeneratePress 설치·활성화, 미사용 테마 삭제
6. 알팩: Seen Analytics · 빠른 버튼 · Header & Footer · Adx 매니저(robots.txt)
7. **카테고리** — 제휴 주제별 (예: AI쿠폰, 여행쿠폰, 게임쿠폰)
   - 제휴 블로그는 애드센스 심사 중이 아니므로 카테고리 여러 개 OK
8. 메뉴: Header + Footer 2개 생성
9. **정책 페이지**: 개인정보처리방침 + DMCA (실제 정보로 수정)
   - Footer 메뉴에 배치

### 4. 검색엔진 등록 (2강 반복)
네이버 서치어드바이저 / 구글 서치콘솔 / Bing / Daum
- ⚠️ 반드시 `https://` (http 아님)
- ⚠️ 소유권 확인 태그를 **1번 블로그와 혼동하지 말 것**. 사이트별로 기록
- 사이트맵(`/sitemap_index.xml`) + RSS(`/feed`) 제출

### 5. 북마크 정리
- `OO 관리자` / `OO 메인` 형태로 사이트별 북마크
- 여러 사이트를 오가므로 이름을 명확히

## 캐시 문제 (자주 발생)

사이트맵/RSS 등록이 안 되거나 변경이 반영 안 되면:
> 호스팅 콘솔 → 워드프레스 관리 → **모든 CloudFront 캐시 삭제** → 재시도

강사가 4강에서 여러 번 강조: "**대부분의 워드프레스 오류는 캐시 문제**"
