### 카테고리 구성
- **사료·간식** — 강아지 사료, 고양이 사료, 습식·건식 비교
- **용품·위생** — 고양이 모래, 스크래처, 털갈이 빗질, 여름 끝 피부
- **펫가전·리빙** — 자동급수기, 자동화장실, 혼자 두기
- **건강·질병**(2026-08-10 신설, 슬러그 `health`) — 노령견, 치아, 심장비대, 발 냄새, 신부전
- **외출·이동**(2026-08-16 신설, 슬러그 `travel`) — 추석 이동. 앞으로 병원 가기·여행·차량 글이 여기 쌓인다

### 클러스터 현황
- **혼자 있는 아이**: 자동급수기 + 자동화장실 + 혼자 두기 (서로 내부링크)
- **고양이 기본**: 사료 + 모래 + 스크래처 + 자동화장실
- **강아지 노령·건강**: 노령견 + 치아 + 심장비대
- **고양이 노령·건강**: 신부전 + 사료 + 모래 + 자동급수기 (수분·소변량으로 이어짐)
- **수분 허브**: 습식·건식(#239)에서 신부전·사료·급수기·치석으로 4갈래 — 상품 있는 글로 흐름을 보냄
- **피부·털**: 털갈이 + 발 냄새 + 여름 끝 피부 (서로 내부링크)
- **목욕·건조**(초안 단계): 드라이룸(/pet-dry-room/)이 도착점. 여름 끝 피부·털갈이 빗질·헤어볼에서 들어오고, 나가는 링크는 2개로 묶어둔다

## 다음 후보

새 글은 **최근 4편과 도입·전개·마무리 조합이 겹치면 안 된다**(스타일가이드 3.5 G).
현재 남은 미사용 유형: 도입 = 장면형·통념 반박·실패담(4편 밖) / 전개 = 기준 나열·시간순·비교 대조·오해 바로잡기·문답 심화 / 마무리 = 요약형·다음 행동(4편 밖).
※ 드라이룸 글(초안)에서 **시나리오 전개**와 **조건부 유보형 마무리(신규)**를 썼다. 둘 다 앞으로 4편은 재사용 금지.

| 순 | 글 | 포맷 | 도입 → 전개 → 마무리 | 붙일 상품 |
|---|---|---|---|---|
| ~~1~~ | ~~추석 연휴, 아이 데리고 본가 가기~~ | — | **실제로는 반론형 → 공간별 → 체크리스트로 씀** | 카시트, 켄넬, 배변패드 |
| 1 | 고양이 한 마리, 1년에 진짜 얼마 들까 | 비용 정리 | 질문형 → 시나리오 → 체크리스트 | 대용량 사료·모래(정기구매) |

### 시각 자료도 매번 다르게
1편 = 차량 배치 도해 · 2편 = 비용 막대그래프 · 3편 = 4주 주차표
(이미 쓴 형태: 좌우 비교표, 기간 타임라인, 도구 도해, 측정법 스텝, 감별 순서도, 병기 진행도, 판단 트리, 주간 루틴 캘린더, 방 배치 평면도, 토사물 색 카드, **소음 눈금자(스케일 바)** — 반복 금지)

### 균형 규칙
강아지↔고양이, 소모품↔고가템, 정보성↔구매성을 번갈아 간다.
**5편 중 1편은 상품 없는 정보성 글**로 신뢰를 쌓는다(#204, #230, #239).
상품 있는 글과 없는 글을 번갈아 간다. #245로 상품 글을 채웠으니 다음은 자유롭다.
카테고리 분포(발행 기준): 건강·질병 5 / 용품·위생 4 / 사료·간식 3 / 펫가전·리빙 3 / 외출·이동 1.
드라이룸 초안이 발행되면 펫가전·리빙이 4가 된다. 최근 5편이 정보형이라 드라이룸은 **구매형 차례**로 넣었다.
