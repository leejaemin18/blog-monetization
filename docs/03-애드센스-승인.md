# Day 3-5+ — 구글 애드센스 승인 (3강)

애드센스 승인은 빠르면 하루, 보통 2~4주 걸립니다(강사 주장).
승인이 안 나와도 제휴마케팅으로 수익화가 가능하므로 여기서 멈출 필요는 없습니다.

> ⚠️ 이 강의의 "10+10 발행 공식"과 "승인율 99%"는 근거가 없습니다.
> 애드센스 **공식 기준은 독창적이고 유용한 콘텐츠**입니다. 아래 절차를 따르되,
> AI 초안을 그대로 대량 발행하지 말고 반드시 사람이 검수·보강하세요.
> ([`91-강사주장-vs-검증사실.md`](91-강사주장-vs-검증사실.md) 참고)

---

## 1. 주제 선정 (3원칙 + 보강)

강사 3원칙:
1. **전문성** — 깊이 있게 다룰 수 있는 주제
2. **일관성** — 단일 카테고리로 묶임
3. **생소한 분야** — 경쟁이 적음

여기에 추가로:
- **실제로 유용한 30개를 쓸 수 있는가** (제목만이 아니라 내용)
- YMYL(건강·재무·법률) 회피

> **주제와 카테고리를 일치시킬 것.** 강의에서 강사가 실수한 것처럼, 음식 블로그인데
> 프린터 글을 쓰면 안 됩니다. 승인 전까지 **카테고리 1개**를 유지합니다.

## 2. 제목 30개 설계 (ChatGPT)

프롬프트: [`../templates/ai-프롬프트.md`](../templates/ai-프롬프트.md) 의 "애드센스 제목 30개"

```
나는 구글 애드센스 승인을 받으려고 해. 추천받은 방식은
1) 전문성 있는 주제 2) 일관성 있는 내용 3) 생소한 분야야.
[내 주제]로 일관되게 카테고리 1개만 지정해서, 검색 의도가 분명한 제목 30개를 뽑아줘.
각 제목은 독자의 구체적 질문/문제를 해결하는 형태로, 과장 없이.
```

- 마음에 안 들면 "더 전문가 있게", "다른 걸로" 등으로 반복
- 30개를 `data/content_ledger.csv`에 옮겨 관리

## 3. 글 작성·발행

### 유료 AI 글쓰기가 있는 경우 (알팩 프로)
- 제목·키워드 입력 → 초안 생성 → 썸네일 생성 → **검수 후** 발행

### 무료(ChatGPT)인 경우
```
[제목]을 SEO에 맞춰 1,500자 이상으로 작성해줘. 과장·허위 없이, 실제 도움이 되게.
```
- 복사 → 워드프레스 글 추가 → 제목/서식 정리
- 이미지: ChatGPT "[제목] 썸네일 만들어줘" → 대표 이미지 설정 (대체텍스트 입력)

> ⚠️ **글자 수(1,500자)보다 "독자의 질문을 충분히 해결했는가"가 중요합니다.**
> AI 초안에 본인의 경험·공식 출처·비교 기준을 추가하세요. 그대로 발행 금지.

### 발행 배치 (강사 방식)
- 초기 **10개는 당일 발행**
- 나머지 **10개는 예약 발행** — 날짜·시간을 **모두 다르게**
- 심사 기간 내내 하루 1개씩 올라가도록: 2주 심사면 14개, 4주면 28개 확보

> 예약 발행은 "승인 공식"이 아니라 **꾸준한 발행을 보여주는 품질 관리 도구**입니다.

발행 전 검수: `python3 tools/compliance.py drafts/글.md` → [`../checklists/발행전-체크리스트.md`](../checklists/발행전-체크리스트.md)

## 4. 애드센스 가입 + 연결

1. 구글 검색 → "구글 애드센스" → 가입하기 → 사이트 주소 + 국가(대한민국) 입력
2. **지급 정보 설정** — 이름(영문), **핀번호 수령 가능한 실주소**
   (수익 10달러 초과 시 우편으로 핀 발송)
3. 사이트 연결:
   - 애드센스 코드 스니펫 → 알팩 Header & Footer에 삽입 → 저장
   - ads.txt 스니펫 → 알팩 Adx 매니저 → ads.txt 내용에 삽입 → 게시함 체크 → 저장
4. **검토 요청** 클릭 → "리뷰 요청됨" → 2~4주 대기

📝 검토 요청한 날짜·시간을 `data/content_ledger.csv` 또는 메모에 기록

## 5. 정책 페이지 추가 (선택)

강사도 "카더라"로 명시. 손해는 없으니 넣어도 됨.
- 페이지 → 새 페이지 → "개인정보 처리방침"
  - ⚠️ AI 초안을 **실제 수집 데이터·실제 이메일에 맞게 수정** 후 게시
- "DMCA" 페이지도 동일

## 6. 거절 대응

거절 사유 대부분은 **"가치가 별로 없는 콘텐츠"**입니다.

1. **거절 사유를 계정 메시지에서 확인** (추측 금지)
2. 사유가 "가치 낮은 콘텐츠"라면:
   - 기존 글의 **품질을 보강** (경험·출처·비교·이미지 추가)
   - 유용한 글 추가 발행 + 예약
3. 재검토 요청
4. 3~4회까지 반복

> ⚠️ **글 수만 늘리는 것으로 해결하려 하지 마세요.** 병목이 키워드인지, 제목인지, 본문 품질인지,
> 사용자 경험인지 진단하는 게 먼저입니다.

### 복수 도메인 전략 (신중히)
강사는 "도메인 5개에 각각 블로그를 만들어 확률을 높인다"고 소개하지만,
이는 **비용·품질 분산 위험**이 큽니다. 사이트 수보다 각 사이트의 품질이 우선입니다.
초보 단계에서는 권장하지 않습니다.
