# 트립닷컴형 쿠폰 소개 사이트 분석

"할인코드·쿠폰을 모아서 소개하고 제휴 링크로 수익화"하는 트립닷컴형 사이트를 조사해
**레이아웃 · 쿠폰 카드 · 이미지 · 수익 구조**를 정리했습니다. 세컨 블로그(여행 할인쿠폰 니치)의
직접 참고 자료입니다.

> 조사일 2026-07. 다수 사이트가 봇 차단(403)이라 원문 전체 열람은 제한 — 검색 요약 + 공개 정보로 정리.
> 실제 사이트를 직접 보며 갱신하세요.

---

## 1. 실제 사례 (조사 중 확인된 한국 쿠폰 사이트)

| 유형 | 사이트 | 성격 |
|---|---|---|
| 단일 브랜드 쿠폰 | trippromocode.isweb.co.kr | 트립닷컴 할인코드 전문 |
| 다중 브랜드 모음 | **salealert.co.kr (할인속보)** | 아고다·마이리얼트립·알리 등 실시간 모음 |
| 쿠폰 팩트체크형 | xincoupon.com, halincoupon.com | "N% 즉시 할인" 검증형 |
| 블로그 글형 | irp-finance.com 등 | "시크릿 쿠폰북 7가지" 식 정보 글 |
| 공식 프로모션 | kr.trip.com/blog/trip-promotions | Trip.com 공식(경쟁 벤치마크) |

> 이들은 **벤치마킹 대상**입니다. 레이아웃·구조만 참고하고 문구·이미지·코드는 복제하지 않습니다.

## 2. 두 가지 포맷

### (A) 쿠폰 애그리게이터형 (salealert류)
여러 브랜드 쿠폰을 **카드 그리드**로 나열. 방문자가 스캔하며 원하는 쿠폰을 찾음.
- 상단: 검색/카테고리 필터(여행·쇼핑·항공 등)
- 본문: **쿠폰 카드 그리드**
- 각 카드: 브랜드명/로고 · 혜택 요약 · 만료일 · "쿠폰 받기" 버튼

### (B) 블로그 글형 (우리 세컨 블로그가 취할 형태)
하나의 키워드("트립닷컴 렌터카 할인코드 2026년 8월")로 **한 편의 글**.
- 도입(왜/누구에게) → **할인코드 표** → 사용법 → FAQ → CTA
- 6강의 HTML 할인코드 테이블이 여기에 해당 → [`../templates/할인코드-테이블.html`](../templates/할인코드-테이블.html)

> 세컨 블로그는 **(B) 블로그 글형**으로 시작하고, 글이 쌓이면 카테고리 페이지가 자연스럽게 (A) 역할.

## 3. 쿠폰 카드 구성 요소 (공통 패턴)

한 쿠폰 = 아래 요소의 조합:

| 요소 | 예시 | 비고 |
|---|---|---|
| 브랜드 식별 | 로고 또는 **텍스트 배지** | 로고는 상표권 주의 → 텍스트 배지 권장 |
| 혜택 요약 | "최대 8% 할인", "신규 22,000원" | 공식 확인값만 |
| 쿠폰 코드 | `TRIPRENT` (복사 버튼) | 없으면 "자동 적용" |
| 유효기간 | "~2026-09-30" | **만료 감시 필수** → `tools/offers.py` |
| CTA 버튼 | "최저가 확인하기" / "쿠폰 받기" | 제휴 딥링크 |
| 조건 | "일부 차종·지역 제외" | 오해 방지 |

## 4. 이미지 사용 패턴 (사용자가 특히 궁금해한 부분)

트립닷컴형 쿠폰 사이트의 이미지는 **정보 전달용**이 핵심 — 화려한 사진보다 **명확한 카드**.

| 위치 | 이미지 | 안전한 대안 |
|---|---|---|
| 대표 썸네일 | "트립닷컴 할인코드 2026년 8월" 텍스트 썸네일 | **Canva/미리캔버스 직접 제작** (로고 대신 텍스트+아이콘) |
| 쿠폰 카드 | 브랜드 로고 | ⚠️ 상표권 → **텍스트 배지 or 공식 미디어킷** |
| 본문 삽화 | 여행지·공항·렌터카 분위기 컷 | **Unsplash/Pexels**의 인물·로고 없는 컷 |
| 사용법 | 예약 화면 캡처 | 최소 인용+출처, 또는 직접 캡처한 본인 화면 |

**핵심**: 쿠폰 사이트는 **브랜드 로고를 카드마다 쓰고 싶은 유혹**이 크지만, 로고는 상표권 리스크.
→ 초기에는 **텍스트 배지 + 여행 분위기 무료 사진(Unsplash)** 조합이 가장 안전하고 깔끔.
→ 상세 규칙: [`21-이미지-전략-무료저작권.md`](21-이미지-전략-무료저작권.md)

## 5. 트립닷컴형의 핵심 경쟁력 = "정보 최신성" (6강 재확인)

경쟁 글 다수가 **만료된 쿠폰·틀린 마감일**을 방치합니다. 여기가 우리의 차별점:
- 공식 페이지에서 **현재 유효한 코드·할인율·마감일**을 확인해 정확히 게시
- 만료 임박/만료를 자동 감시 → `python3 tools/offers.py --days 7`
- 글에 **확인일** 명시 ("2026-07-31 기준")
- 만료되면 즉시 수정/삭제

## 6. 수익 구조

| 제휴처 | 수수료(강의/조사값, ⚠️재확인) | 링크 방식 |
|---|---|---|
| Trip.com Partners | 최대 7% (지역·상품·캠페인별) | 항공/호텔/렌터카 딥링크 |
| 마이리얼트립 | 공식 확인 | 상품 링크 |
| 아고다·부킹 | 공식 확인 | 딥링크 |
| 쿠팡 파트너스 | 기본 3% | 상품 딥링크 (여행용품 등) |

> 여행 쿠폰 니치는 **단가·수수료율이 상대적으로 높은** 편이라 트립닷컴형이 매력적.
> 단, 수수료율은 전부 실행 직전 공식 재확인 (`data/offers.csv`에 확인일 기록).

## 7. 세컨 블로그 적용안 (여행 할인쿠폰으로 갈 경우)

```
카테고리: 항공쿠폰 / 호텔쿠폰 / 렌터카쿠폰 / 국가별(일본·동남아)
글 형태: 키워드별 1편 (예: "트립닷컴 렌터카 할인코드 2026년 8월")
구조: 광고표시 → 도입 → 할인코드 표(HTML) → 사용법 → FAQ → CTA
이미지: 텍스트 썸네일(직접제작) + 여행 분위기 무료사진 + (필요시)공식 미디어킷
링크: 딥링크 1~3개, "최저가 확인하기"
갱신: offers.csv에 만료일 등록, 매주 offers.py로 점검
```

바로 쓸 수 있는 예시 초안(개념) → 필요 시 니치 확정 후 생성.
스타일 규칙 → [`../templates/제휴글-스타일가이드.md`](../templates/제휴글-스타일가이드.md)
