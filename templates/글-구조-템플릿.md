# 제휴 글 구조 템플릿 (5강 작성법)

새 글을 쓸 때 이 골격을 복사해서 채웁니다. `drafts/` 폴더에 저장 후
`python3 tools/compliance.py drafts/파일.md` 로 검사하세요.

---

```markdown
# [핵심키워드 + 구체적 상황/혜택 + 시점]
<!-- 예: Trip.com 렌터카 할인 코드 쿠폰 포함 2026년 8월 최신 -->

> 💡 이 글에는 제휴 링크가 포함되어 있으며, 링크를 통해 구매·예약하시면
> 작성자가 일정액의 수수료를 받습니다. (구매자 추가 부담 없음)
<!-- ↑ 광고 표시: 제목 바로 아래 첫 부분. 필수. -->

## 이런 분께 (도입)
- 누가, 어떤 상황에서, 어떤 기준으로 선택하면 좋은지
- 결론 미리보기 (독자가 스크롤 안 해도 핵심을 알게)

## 핵심 정보 표 / 할인코드 표
<!-- 워드프레스에서는 /html 블록에 templates/할인코드-테이블.html 삽입 -->
| 구분 | 내용 | 유효기간 |
|---|---|---|
| ... | ... | ~YYYY-MM-DD |

## 비교 기준 (본문)
- 가격 / 규격 / 설치 / 장단점 / 대상 / 주의사항
- 근거 있는 비교만. "근거 없는 TOP5" 금지

## 실제 경험 / 공식 사양 / 제3자 후기  ← 반드시 구분
- **직접 경험**: (실제로 써본 것만)
- **공식 사양**: (출처 URL + 확인일)
- **제3자 후기 인용**: (출처 명시)

## 자주 묻는 질문 (FAQ)
- 배송 / 설치 / 호환 / 취소 / 쿠폰 적용 / 모델 차이
- 정책·가격에는 날짜 표시

## 마무리
- 출처 URL과 확인일
- 개인 결과 편차 고지 (수익/효과 보장 표현 금지)

---
확인일: YYYY-MM-DD · 정보는 공식 페이지 기준이며 변경될 수 있습니다.
```

---

## 발행 전 7가지 최종 점검 (5강)
1. 사실 — 수치·모델명·수수료를 공식과 대조했는가
2. 링크 — 전용링크가 의도한 페이지로 가는가 (모바일 포함)
3. 광고 표시 — 제목/첫 부분에 있는가
4. 저작권 — 이미지·문구가 권리 확인된 것인가
5. 오탈자
6. 모바일 — 표·버튼이 깨지지 않는가
7. 플랫폼 규정 — 해당 채널 정책을 지켰는가

→ 자동 검사: `python3 tools/compliance.py`
