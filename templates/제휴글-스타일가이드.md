# 제휴 글 스타일 가이드 (상위노출 벤치마킹 실전판)

[`../docs/20-벤치마킹-상위노출-분석.md`](../docs/20-벤치마킹-상위노출-분석.md)에서 익힌 상위노출 패턴을
**바로 쓸 수 있는 규칙**으로 옮겼습니다. 새 글을 쓸 때 이 카드를 옆에 두세요.

> 채널 규칙: **네이버 블로그** = 쇼핑커넥트 + 텍스트 링크 분리형, 저품질 극도 주의.
> **워드프레스(세컨)** = 쿠팡 위젯/배너 자유, 검색 제재 거의 없음.

## 0. 진정성으로 "필요하다"고 느끼게 — 전환 심리 (★ 최우선)

> 상위 글들의 공통점: **팔려고 하지 않고, 내 고민을 먼저 읽어준다.** 스펙 나열이
> 아니라 "나도 저랬는데" 하는 공감 → 실사용 관찰 → 솔직한 장단점 순으로 신뢰를 쌓는다.
> ("사람은 합리보다 감정으로 선택한다 / 이야기가 마음을 움직인다" — 상위 가이드 관찰)

**반드시 넣는 5가지 장치**

1. **Pain point 도입** — 제품이 아니라 *보호자의 고민*으로 시작한다.
   - ❌ "오늘은 로얄캐닌을 소개합니다."
   - ✅ "사료만 바꾸면 며칠씩 안 먹고 뱉어내서, 냄새 맡고 돌아서는 뒷모습에 속상했던 적 있으시죠."
2. **1인칭 실사용 관찰** — "제가 며칠 줘보니…" + *구체적 변화*.
   - ✅ "3일째부터 그릇을 싹 비우더라고요. 변 상태도 눈에 띄게 단단해졌어요."
3. **단점·조건 솔직하게** — 신뢰의 핵심. 조건부로 서술.
   - ✅ "알갱이가 작은 편이라 대형견은 금방 먹어요. 소·중형견한테 잘 맞았어요."
   - 상위 글 관찰: "지성 피부엔 좋았지만 건성엔 건조할 수 있다" 식 조건부 후기가 신뢰↑ + SEO↑.
4. **before / after 대비** — 숫자·상황으로. 감정 단어보다 관찰된 사실.
5. **"이런 분께"로 좁히기** — 만능이라 하지 말고 *맞는 대상*을 지정.
   - ✅ "잘 안 먹는 편식냥·중형견 다견 가정이면 특히." / "활동량 적은 노령견엔 다른 라인이 나아요."

**과장과의 선(=금지어와 직결):** 단정("무조건 좋다") ❌ → 조건·경험 서술 ✅.
금지어(최고·무조건·100%·완벽·유일·강력추천·초특가)는 진정성 자체를 깨뜨린다.

**글 포맷:** *문제해결형 + BEST N 리스트형* 결합. 한 글에 검증한 제품 **1~3개(리스트형이면 5~7개)**,
각 상품을 소제목으로 나눠 "이 고민 → 이 제품이 이래서 → 이런 분께" 흐름을 반복.

## 1. 말투 — "광고를 정보로 바꾼다"

| 하기 | 피하기 |
|---|---|
| 친근한 존댓말 (~해요, ~더라고요, ~았어요) | 딱딱한 "~하십시오", 과한 이모지 남발 |
| 1인칭 경험담 ("직접 써보니", "내돈내산") | 실제 안 써보고 후기처럼 (부당광고) |
| 장점 + **단점·주의사항** 함께 | 장점만 나열, "무조건 사세요" |
| 짧은 문장·문단(3~4문장), 줄바꿈 | 긴 문단, 벽 같은 텍스트 |
| 구체적 수치·상황("14인용, 설치 60cm 필요") | 두루뭉술 "좋아요", "괜찮아요"만 |

**금지어**(광고법 + 저품질): 최고 · 무조건 · 100% · 완벽 · 유일 · 강력추천 · 초특가(허위)

## 2. 제목 공식 (★ "고르는 법" 금지 — 다양화)

핵심 키워드는 **맨 앞**에 유지하되, **매번 다른 패턴**으로 쓴다.
❌ "○○ 고르는 법", "추천보다 중요한 것" 같은 틀을 **반복하지 않는다**(지겹고 클릭 안 됨).

**패턴 로테이션 (돌려쓰기)**
| 유형 | 예시 |
|---|---|
| 리스트+연도 | 노령견 사료 추천 5선, 7살부터 이건 바꿨어요 (2026) |
| 문제해결 | 노령견이 사료를 안 먹을 때 — 바꿔야 할 3가지 |
| 질문 후킹 | 우리 강아지도 이제 노령견? 7살부터 챙길 것들 |
| 비교 | 벤토 vs 두부 모래, 우리집엔 뭐가 맞을까 |
| 경험/실속 | 노령견 관절, 계단 하나로 확 달라졌어요 |
| 총정리 | 고양이 신장병, 집사가 알아야 할 전부 (사료·물·신호) |

- 핵심 키워드 **맨 앞**(또는 앞 30자 이내) + **숫자/연도** 넣기 → 검색·클릭 둘 다 유리
- 25~32자, 사람이 읽는 문장으로. 키워드 나열 금지.
- 포커스 키워드 = 제목의 그 핵심구 그대로 (예: "노령견 사료 추천")

## 3. 글 골격 (도입 → 본문 → FAQ → 결론)

```markdown
[제목]

> 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
  ↑ 첫 부분(또는 제목)에 텍스트로. 첫 100단어에 핵심 키워드도 함께.

## (도입) 왜 이걸 찾게 됐나
- 인사 대신 상황·문제 제기 2~3문장. 결론 미리보기.

## (본문) 소제목 3~5개 — 각 소제목에 키워드
- 비교표 / TOP5 / 장단점 / 설치·사용법
- 직접 찍은 사진을 300~500자마다 1장
- 직접경험 / 공식사양 / 제3자후기 구분

## 자주 묻는 질문 (5~7개)
- 배송·설치·호환·취소·쿠폰 적용·모델 차이

## (결론) 요약 + 자연스러운 CTA
- 여기(또는 본문 자연 위치)에 링크 1~3개
확인일: YYYY-MM-DD · 출처 URL
```

- 목표 분량: **1,500~3,000자**, 이미지 **6~13장**, (가능하면) 1분+ 영상
- 체류시간 3분을 의식 — 스캔되지 않고 읽히게

> ⚠️ 위 골격은 **기본형일 뿐 매번 따라야 할 틀이 아니다.** 반드시 아래 3.5를 함께 볼 것.

## 3.5 구조 다양화 (★ 글이 서로 닮아 보이면 안 된다)

같은 틀을 반복하면 독자는 "또 그 글"로 느끼고, 검색엔진도 양산형으로 본다.
**연속한 글은 아래 항목에서 최소 3가지가 달라야 한다.**

### A. 도입부 유형 — 돌려쓰기
1. **장면형** — 특정 순간 묘사 ("하품할 때 훅 끼치는 입냄새")
2. **질문형** — 독자에게 바로 물음 ("지금 쓰는 모래, 아이가 정말 좋아할까요?")
3. **통념 반박형** — "노령견은 저단백? 그거 반은 틀렸어요"
4. **숫자·사실형** — "치태가 치석으로 굳는 데 딱 2~3일이에요"
5. **실패담형** — "저는 이거 사고 두 달을 방치했어요"
6. **결론 선치기형** — 첫 줄에 답부터 던지고 근거를 뒤에

### B. 본문 전개 유형 — 돌려쓰기
1. **기준 나열형** — 고를 때 볼 항목 3~5개 (지금까지 과다 사용, 당분간 자제)
2. **단계 루틴형** — 1단계 → 2단계 → 3단계
3. **비교·대조형** — A형 vs B형, 집에서 vs 병원
4. **시간순형** — 첫날 / 1주 / 1개월, 또는 하루 일과
5. **시나리오형** — "이런 집이면 이걸, 저런 집이면 저걸"
6. **오해 바로잡기형** — 흔한 오해 5개를 하나씩 격파
7. **문답 심화형** — 실제 질문 하나를 끝까지 파고들기

### C. 마무리 유형 — 돌려쓰기
1. 요약형 ("정리하면 ~ 순으로") — **연속 사용 금지, 이미 많이 씀**
2. **한 가지만 기억형** — "다 잊어도 이것만은"
3. **다음 행동형** — 오늘 당장 할 일 하나 제안
4. **여운형** — 짧게 감정으로 닫기 (요약 없이)
5. **체크리스트형** — 구매 직전 최종 확인 목록

### D. 매번 넣지 말 것 (기계적으로 붙는 블록들)
- **FAQ**: 2편에 1편 정도만. 넣더라도 개수를 3~6개로 바꾸기
- **"이런 신호는 병원부터" 인용 블록**: 건강 주제일 때만. 위치도 고정하지 말고 본문에 녹이기도
- **인포그래픽 자리**: 항상 "기준" 소제목 아래일 필요 없음. 도입 직후 / 마무리 직전도 가능
- **"함께 보면 좋은 글"**: 제목을 바꿔도 됨 ("이 글도 도움이 돼요", "이어서 읽기")

### E. 문체·리듬도 바꾸기
- 불릿 남발 금지 — 어떤 글은 **서술 위주**로 가기
- 소제목 문체를 섞기: 질문형("정말 매일 닦아야 할까") / 선언형("치석은 3일이면 굳는다") / 명사형("모래 교체 주기")
- 표를 쓰는 글, 안 쓰는 글을 번갈아

### F. 구조 이력 (새 글 쓰기 전 반드시 확인 → **최근 4편**과 다른 조합 선택)

| 글 | 도입 | 전개 | 마무리 | FAQ |
|---|---|---|---|---|
| 노령견 사료 (/senior-dog-care/) | 장면형 | 기준 나열 | 요약형 | O |
| 강아지 치석 (/dog-dental-care/) | 장면형 | 단계 루틴 | 요약형 | O |

### G. 로테이션도 굳지 않게

목록을 정해두고 순서대로 돌리면, 그 순환 자체가 또 패턴이 된다.

- **같은 유형은 최근 4편 안에서 재사용 금지** (직전 2편이 아니라 4편)
- **매 5편마다 목록에 없는 유형을 하나 새로 만들어** 시도하고, 성공하면 A~C 목록에 추가한다
- 잘 먹힌 조합이라도 **연속 사용 금지.** "좋으니까 또"가 가장 지루해지는 길이다
- 주제 선정도 마찬가지 — 강아지/고양이, 소모품/고가템, 정보성/구매성을 번갈아 간다

## 3.6 지속 다변화 장치 (★ 한 번 정하고 끝이 아니다)

### A. 반복 상투구 — 실제로 이렇게 굳어 있었다

세 편의 첫 문장과 마지막 문단이 사실상 같은 템플릿이었다.

| | 굳어버린 패턴 |
|---|---|
| 첫 문장 | "**OO를 검색하게 되는 건, 대개 ~ 때예요. 저도 ~ 기억이 나요.**" |
| 마무리 | "**정리하면 OO는 ~ 순으로 ~ 돼요. 무엇보다 ~. 관련해서 아래 글도 함께 보면 도움이 돼요.**" |
| 곳곳 | "우리 아이" (한 글에 3~4회씩) |

**금지·주의 표현** — 쓰기 전에 최근 4편에 있었는지 확인하고, 있으면 다른 말로:
- `~를 검색하게 되는 건` / `~를 찾아보게 되는 건`
- `저도 ~ 기억이 나요` / `저도 ~ 싶었어요`
- `정리하면` (마무리 첫머리)
- `~ 순으로 챙기면 돼요` / `~ 순으로 따져보면 돼요`
- `관련해서 아래 글도 함께 보면 도움이 돼요`
- `우리 아이` — 한 글에 2회까지. 대신 품종·나이·이름 상황("13살 말티즈라면", "그 아이")으로 바꾸기
- `무엇보다`, `핵심은`, `결론부터 말하면` — 매 글 반복 금지

> 1인칭 경험을 흉내 낸 문장("저도 ~했어요")은 **원래 지어내면 안 되는 것**이기도 하다.
> 운영자의 실제 경험이 아니면 공감 표현은 **독자를 향한 서술**로("그 순간 덜컥 겁이 나죠")로 쓴다.

### B. 글 포맷 자체를 바꾸기 — **5편 중 1편은 가이드가 아닌 글**

계속 "고르는 기준 안내"만 쓰면 사이트 전체가 지루해진다. 아래에서 골라 섞는다.

1. **실수 모음** — "자동화장실 사고 후회한 이유 5가지"
2. **비용 정리** — "1년 키우면 실제로 얼마 드나 (항목별)"
3. **오해 격파** — "아직도 믿는 반려동물 속설 7가지"
4. **초보 로드맵** — "입양 첫 달, 주차별로 할 일"
5. **사례 스터디** — 지식iN·커뮤니티에서 자주 나오는 상황 하나를 끝까지 파기
6. **계절·이슈** — 폭염, 명절 집 비우기, 이사
7. **체크리스트 제공** — 독자가 저장해 쓰는 표 한 장
8. **비교 단독** — 두 제품군만 정면 비교 (A형 vs B형)

### C. 시각 자료도 돌려쓰기

`criteria.svg` 같은 **좌우 비교표만 반복하지 말 것.**
체크리스트 / 순서도(플로우) / 타임라인(주차별) / 막대·비율 그래프 / 라벨 읽는 법 도해 / 한 장 요약 카드 등으로 형태를 바꾼다.

### D. 발행 전 자가 점검 (매번)

```
1. 최근 4편의 첫 문장과 내 첫 문장을 나란히 놓고 읽는다 → 비슷하면 다시 쓴다
2. 최근 4편의 마지막 문단과 내 마무리를 나란히 놓는다 → 비슷하면 유형을 바꾼다
3. 3.5 F 이력표에서 도입·전개·마무리 조합이 겹치는지 본다
4. A의 금지 표현이 들어갔는지 훑는다
5. 최근 4편이 전부 "가이드"였다면 이번엔 B에서 다른 포맷을 고른다
6. `python3 tools/humanize.py <초안> --fix` 를 돌린다 → S1이 0이어야 발행된다
```

### E. AI 티 — 문장 습관 셋 (★ 쓰면서부터 피한다)

`tools/humanize.py`가 잡아주지만, **검사에 걸리기 전에 안 쓰는 게 낫다.**
셋 다 우리 글 11편을 실측해서 나온 실제 버릇이다(근거: `docs/운영-가이드.md` 2.6).

**① "A가 아니라 B" — 글당 1회.**
AI 글 판별에서 가장 센 신호다(AI가 사람보다 9.2배, 개인 블로그 대비 18배).
우리는 6편 전부에서 썼고, 그것도 **매번 소제목 결론 자리**였다.

> ✗ 심장병은 완치가 아니라 관리하는 병이에요.
> ✓ 심장병은 관리하는 병입니다. 약으로 완치되지는 않지만, 잘 관리하면 오래 함께 지내요.

정말 대비가 핵심인 한 곳에만 쓰고, 나머지는 **그냥 단언**한다.

**② 연결어미 뒤 쉼표 — 찍지 않는다.**
`~하고,` `~하지만,` `~해서,` `~하면서,` — 한국어에선 대부분 없어도 된다.
영어 습관이라 AI 글에 4.84배 많이 나온다. 뜻이 안 바뀌니 `--fix`가 지워주지만,
애초에 안 찍는 게 낫다. (단, "사고, 질병"처럼 **명사 뒤 쉼표는 정상**이다.)

**③ 글마다 긴 문장 한둘.**
AI는 짧은 문장만 찍어낸다(100자+ 문장이 사람의 1/11). 우리 글도 5편은 0개였다.
문단마다 단문 1~2개를 넣되, **인접한 두 문장을 이어 붙인 긴 호흡을 하나** 만든다.
내용을 더하지 말고 **잇기만** 한다.

## 4. 링크 배치 규칙

| 규칙 | 값 |
|---|---|
| 한 글당 링크 | **1~3개** (본문 절반이 링크면 위험) |
| 위치 | **후반부**(가격·구매처) 또는 각 제품 설명 아래. 초반 배치 금지 |
| 앵커 문구 | "최저가 확인하기" / "○○ 보러 가기" / "쿠팡 구매하러 가기" |
| 반복 | 같은 상품 링크를 여러 글에 도배 금지 |
| 비율 | **쿠팡 글 : 일반 글 = 1 : 3~5** (일반·정보 글을 훨씬 많이) |
| 네이버 팁 | 위젯 스크립트 대신 **텍스트 앵커 링크**. 필요 시 링크를 첫 댓글에(광고표시는 본문 유지) |

> **워드프레스 BEST N 리스트형 예외:** 제재가 거의 없는 세컨 블로그에서는
> **상품마다 그 상품 설명 바로 아래 링크/배너 1개**를 두는 게 표준(상위 리스트형 글 관찰).
> 즉 5개 제품이면 링크 5개 + 마무리 종합 CTA도 자연스럽다. 단 **각 링크는 반드시
> 해당 상품 설명·후기 끝에 붙고**, 문단 대비 링크가 과반이 되지 않게. 도입부 단독 배치만 피한다.

## 6.5 새 글 SEO 발행 공식 (★ 처음부터 Rank Math 초록으로 태어나게)

새 글은 **발행 시점에 이미 최적화**되도록 아래를 전부 충족해서 쓴다. (나중에 패치 X)

**포커스 키워드 = 제목의 핵심구.** 그 키워드를 아래 위치에 자연스럽게 넣는다:
- [ ] **제목 맨 앞**(앞 30자) — 예: "노령견 사료 추천 …"
- [ ] **첫 문단(첫 10%)** 에 1회 — pain point 도입 문장 안에 녹여서
- [ ] **소제목(H2) 최소 1개**에 포함
- [ ] **이미지 1장 이상의 alt**에 포함
- [ ] 본문 전체에 자연스럽게 (밀도 0.5~1%, **도배 금지** — 억지로 1% 맞추지 말 것)

**구조 요건**
- [ ] **본문 600단어 이상** (짧으면 관리팁·FAQ로 알맹이 보강)
- [ ] **내부 링크 2~4개** — 관련 글로(맨 아래 "함께 보면 좋은 글")
- [ ] **외부 dofollow 권위 링크 1개** — AAFCO·수의 자료 등 (제휴 링크는 nofollow라 별도 필요)
- [ ] **주제 맞춤 상품 카드**(재호스팅된 이미지) + 상단 **광고표시 문구**
- [ ] **하단 다이나믹 배너**
- [ ] 슬러그 = **짧은 영문**(dog-food-guide 식)

**메타 설명**: 굳이 손입력 안 해도 됨(Rank Math 자동 생성 + 첫 문단 키워드로 충당). 넣으면 CTR엔 +.
**안 쫓아도 되는 항목**: URL에 한글 키워드(영문 슬러그 유지), 키워드 밀도 1% 강제, TOC(플러그인 필요) — 순위 영향 적음.

> 이 공식대로 쓰면 발행 즉시 Rank Math 대부분 초록. 운영자는 편집기에서 **포커스 키워드 한 칸만** 입력.
- [ ] **구조 다양화 확인** — 3.5 F 이력표에서 최근 4편과 도입·전개·마무리 조합이 겹치지 않는지

## 8. 지식iN 답변 원칙 (블로그 홍보용)

지식iN 운영정책 고지문:

> 광고주로부터 소정의 경제적 대가를 받고 특정 상품에 대한 추천 또는 후기글을 올리는 경우,
> 이러한 광고주와의 경제적 이해관계를 소비자들이 쉽게 알 수 있도록
> **글 제목 또는 답변의 첫 부분 또는 끝부분 등 적절한 위치에 공개**하여야 합니다.

우리 블로그 글에는 쿠팡 파트너스 링크가 있으므로, **블로그 링크를 다는 답변은 이 조항의 대상**이다.

### 반드시 지킬 것
1. **답변 본문에서 특정 제품을 추천하지 않는다.** 제품명·모델명을 거론하며 권하는 형태가 정책이 겨냥하는 대상이다. 답변은 원리·판단 기준·병원 신호까지만.
2. **쿠팡 제휴 링크를 답변에 직접 붙이지 않는다.** 자동 필터로 삭제·정지 위험.
3. **블로그 링크를 달 때는 이해관계를 밝힌다.** 끝부분에 아래 한 줄:
   ```
   제가 운영하는 블로그이고, 본문에 쿠팡 파트너스 제휴 링크가 포함되어 있어
   수수료를 받을 수 있다는 점 미리 밝힙니다. 답변 내용 자체는 특정 제품과 무관해요.
   ```
4. **링크는 출처 칸에.** 본문 링크보다 광고 필터에 덜 걸린다.
5. **하루 답변 3개, 그중 링크는 1개까지.** 계정이 초수인 동안은 더 보수적으로.
6. **링크는 매번 다른 글로.** 같은 주소 연속 금지.

### 채택을 먼저 쌓는다
현재 계정은 초수이고 중수까지 채택 답변이 부족하다. 링크 있는 답변은 채택률이 떨어지므로,
**답변 0개인 최신 질문에 빠르게 답해 채택을 모으는 것**이 우선이다.
미답변 질문은 `kin-unanswered.yml` 워크플로우로 그 시점에 조회한다(미리 뽑아두면 그사이 답변이 달림).

### 복붙 시 서식
답변 텍스트는 **코드블록으로 전달**한다. 굵게·인용 서식이 붙으면 지식iN 에디터에 배경색·글자색이 그대로 딸려간다.
붙여넣기는 `Ctrl+Shift+V`(맥 `⌘+Shift+V`) 또는 에디터의 서식 지우기(Tx) 사용.
