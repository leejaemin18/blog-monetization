# 제휴 글 스타일 가이드 (상위노출 벤치마킹 실전판)

[`../docs/20-벤치마킹-상위노출-분석.md`](../docs/20-벤치마킹-상위노출-분석.md)에서 익힌 상위노출 패턴을
**바로 쓸 수 있는 규칙**으로 옮겼습니다. 새 글을 쓸 때 이 카드를 옆에 두세요.

> 채널 규칙: **네이버 블로그** = 쇼핑커넥트 + 텍스트 링크 분리형, 저품질 극도 주의.
> **워드프레스(세컨)** = 쿠팡 위젯/배너 자유, 검색 제재 거의 없음.

---

## 0. 진정성으로 "필요하다"고 느끼게 — 전환 심리 (★ 최우선)

> 상위 글들의 공통점: **팔려고 하지 않고, 내 고민을 먼저 읽어준다.** 스펙 나열이
> 아니라 "나도 저랬는데" 하는 공감 → 실사용 관찰 → 솔직한 장단점 순으로 신뢰를 쌓는다.
> ("사람은 합리보다 감정으로 선택한다 / 이야기가 마음을 움직인다" — 상위 가이드 관찰)

**반드시 넣는 5가지 장치**

1. **Pain point 도입** — 제품이 아니라 *보호자의 고민*으로 시작한다.
   - ❌ "오늘은 로얄캐닌을 소개합니다."
   - ✅ "사료만 바꾸면 며칠씩 안 먹고 뱉어내서, 냄새 맡고 돌아서는 뒷모습에 속상했던 적 있으시죠."
2. **1인칭 실사용 관찰** — "제가 며칠 줘보니…" + *구체적 변화*.
   - ✅ "3일째부터 그릇을 싹 비우더라고요. 변 상태도 눈에 띄게 단단해졌어요."
3. **단점·조건 솔직하게** — 신뢰의 핵심. 조건부로 서술.
   - ✅ "알갱이가 작은 편이라 대형견은 금방 먹어요. 소·중형견한테 잘 맞았어요."
   - 상위 글 관찰: "지성 피부엔 좋았지만 건성엔 건조할 수 있다" 식 조건부 후기가 신뢰↑ + SEO↑.
4. **before / after 대비** — 숫자·상황으로. 감정 단어보다 관찰된 사실.
5. **"이런 분께"로 좁히기** — 만능이라 하지 말고 *맞는 대상*을 지정.
   - ✅ "잘 안 먹는 편식냥·중형견 다견 가정이면 특히." / "활동량 적은 노령견엔 다른 라인이 나아요."

**과장과의 선(=금지어와 직결):** 단정("무조건 좋다") ❌ → 조건·경험 서술 ✅.
금지어(최고·무조건·100%·완벽·유일·강력추천·초특가)는 진정성 자체를 깨뜨린다.

**글 포맷:** *문제해결형 + BEST N 리스트형* 결합. 한 글에 검증한 제품 **1~3개(리스트형이면 5~7개)**,
각 상품을 소제목으로 나눠 "이 고민 → 이 제품이 이래서 → 이런 분께" 흐름을 반복.

## 1. 말투 — "광고를 정보로 바꾼다"

| 하기 | 피하기 |
|---|---|
| 친근한 존댓말 (~해요, ~더라고요, ~았어요) | 딱딱한 "~하십시오", 과한 이모지 남발 |
| 1인칭 경험담 ("직접 써보니", "내돈내산") | 실제 안 써보고 후기처럼 (부당광고) |
| 장점 + **단점·주의사항** 함께 | 장점만 나열, "무조건 사세요" |
| 짧은 문장·문단(3~4문장), 줄바꿈 | 긴 문단, 벽 같은 텍스트 |
| 구체적 수치·상황("14인용, 설치 60cm 필요") | 두루뭉술 "좋아요", "괜찮아요"만 |

**금지어**(광고법 + 저품질): 최고 · 무조건 · 100% · 완벽 · 유일 · 강력추천 · 초특가(허위)

## 2. 제목 공식

```
[핵심키워드 맨앞] + [구체 상황/모델/시기] + [의도어 1~2]      ← 25자 이내
예) 쿠쿠 14인용 식기세척기 설치 후기 (소음·전기세 총정리)
예) Trip.com 렌터카 할인코드 2026년 8월 최신 (쿠폰 적용법)
```
- 핵심 키워드를 **맨 앞**에, 띄어쓰기 정확히
- 동의어를 함께: 할인코드 ≈ 쿠폰 ≈ 특가 / 후기 ≈ 리뷰 ≈ 내돈내산
- 나열 금지 — 사람이 읽는 문장으로

## 3. 글 골격 (도입 → 본문 → FAQ → 결론)

```markdown
[제목]

> 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
  ↑ 첫 부분(또는 제목)에 텍스트로. 첫 100단어에 핵심 키워드도 함께.

## (도입) 왜 이걸 찾게 됐나
- 인사 대신 상황·문제 제기 2~3문장. 결론 미리보기.

## (본문) 소제목 3~5개 — 각 소제목에 키워드
- 비교표 / TOP5 / 장단점 / 설치·사용법
- 직접 찍은 사진을 300~500자마다 1장
- 직접경험 / 공식사양 / 제3자후기 구분

## 자주 묻는 질문 (5~7개)
- 배송·설치·호환·취소·쿠폰 적용·모델 차이

## (결론) 요약 + 자연스러운 CTA
- 여기(또는 본문 자연 위치)에 링크 1~3개
확인일: YYYY-MM-DD · 출처 URL
```

- 목표 분량: **1,500~3,000자**, 이미지 **6~13장**, (가능하면) 1분+ 영상
- 체류시간 3분을 의식 — 스캔되지 않고 읽히게

## 4. 링크 배치 규칙

| 규칙 | 값 |
|---|---|
| 한 글당 링크 | **1~3개** (본문 절반이 링크면 위험) |
| 위치 | **후반부**(가격·구매처) 또는 각 제품 설명 아래. 초반 배치 금지 |
| 앵커 문구 | "최저가 확인하기" / "○○ 보러 가기" / "쿠팡 구매하러 가기" |
| 반복 | 같은 상품 링크를 여러 글에 도배 금지 |
| 비율 | **쿠팡 글 : 일반 글 = 1 : 3~5** (일반·정보 글을 훨씬 많이) |
| 네이버 팁 | 위젯 스크립트 대신 **텍스트 앵커 링크**. 필요 시 링크를 첫 댓글에(광고표시는 본문 유지) |

> **워드프레스 BEST N 리스트형 예외:** 제재가 거의 없는 세컨 블로그에서는
> **상품마다 그 상품 설명 바로 아래 링크/배너 1개**를 두는 게 표준(상위 리스트형 글 관찰).
> 즉 5개 제품이면 링크 5개 + 마무리 종합 CTA도 자연스럽다. 단 **각 링크는 반드시
> 해당 상품 설명·후기 끝에 붙고**, 문단 대비 링크가 과반이 되지 않게. 도입부 단독 배치만 피한다.

## 5. 이미지 규칙

| 규칙 | 값 |
|---|---|
| 개수/간격 | 6~13장, 300~500자마다 1장 |
| 출처 ✅ | 쿠팡 **상품 대표이미지(썸네일)**, **직접 촬영/제작** |
| 출처 ❌ | 상세페이지 이미지, 상품평 사용자 사진 (저작권) |
| 썸네일 텍스트 | 짧은 단어만("1+1", "무소음"), 상품 중앙 또렷 |
| alt/파일명 | 핵심 키워드 삽입 |
| 규격 | 1000×1000px(최소 500×500), JPG/PNG |
| 링크 결합 | 네이버=사진·링크 분리 / WP·티스토리=위젯·배너(이미지=링크) 가능 |

## 6. 광고 표시 (필수, 첫 부분 텍스트)

```
이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```
- ✅ "제공받습니다"(확정) / ❌ "받을 수 있음"(불확정), "일환입니다"(대가 불명확)
- 위치: 제목 또는 첫 문단. 글 끝 작은 글씨 = 처벌 대상
- 네이버 쇼핑커넥트: '쇼핑 커넥트' 버튼 삽입 시 문구 자동 → 확인만
- ⚠️ 문구를 이미지로만 넣는 트릭은 회색지대 — 텍스트 유지 권장
- 더 많은 문구 → [`광고표시-문구.md`](광고표시-문구.md)

## 7. 저품질 방어선 (네이버 특히)

- 제휴 링크 도배·동일 링크 반복 ❌
- 외부링크 과다 ❌ (네이버는 유출 비선호)
- 복붙·중복 콘텐츠, 중복 이미지 ❌
- 키워드 도배 ❌ (한 단락 1~2개)
- 발행 후 잦은 수정 ❌
- 워드프레스 글을 네이버에 그대로 복제 ❌ → **채널별 재작성**
