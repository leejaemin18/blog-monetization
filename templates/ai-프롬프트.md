# AI 프롬프트 모음 (사람 검수 필수)

강의 전반에서 ChatGPT를 사용합니다. 아래는 검증·안전 요소를 보강한 프롬프트입니다.
**모든 AI 출력은 사람이 사실·저작권·광고표시를 최종 검수한 뒤 사용합니다.**

---

## 1. 애드센스 제목 30개 (3강)

```
나는 구글 애드센스 승인을 받으려고 해. 추천받은 방식은
1) 전문성 있는 주제 2) 일관성 있는 내용 3) 남들이 잘 모르는 생소한 분야야.
주제: [내 주제]
이 주제로 카테고리 1개 안에 묶이는, 검색 의도가 분명한 글 제목 30개를 만들어줘.
조건:
- 각 제목은 독자의 구체적 질문/문제를 해결하는 형태
- 과장·허위 없이, 실제로 유용한 정보를 담을 수 있는 것만
- 클릭베이트 금지
```

## 2. 애드센스 승인용 본문 (3강)

```
제목: [제목]
위 제목으로 SEO를 고려해 1,500자 이상 글을 써줘.
조건:
- 독자의 질문을 충분히 해결하는 것이 목표 (글자 수 채우기 아님)
- 사실만. 확실하지 않은 수치·주장은 넣지 말 것
- 내가 나중에 직접 경험·공식 출처·비교 기준을 추가할 자리를 [보강] 으로 표시
```
> 발행 전: [보강] 표시 자리를 본인 경험·출처로 채우고, 사실을 검증하세요.

## 3. 제휴 글 초안 (5·6강)

```
제목: [제목]
대상 독자: [누가]
검색 의도: [정보형/비교형/구매형/문제해결형 중 하나]
반드시 포함할 사실(내가 확인함): [가격/할인율/마감일/모델명 등]
금지: 없는 할인·과장 표현, 직접 경험한 것처럼 쓰기, 클릭 강요
출력: 도입 → 비교 표 → 실사용/공식사양/후기 구분 → FAQ → 마무리
글 첫 부분에 '제휴 링크 포함, 구매 시 수수료를 받습니다' 문구를 넣어줘.
```
> AI에게 가격·쿠폰·수수료를 **기억으로 채우게 하지 마세요.** 반드시 내가 확인한 값만 전달.

## 4. 메타설명 (6강)

```
제목: [제목]
이 제목을 토대로 검색 결과에 표시될 메타설명을 200자 내외로 작성해줘.
핵심 혜택·대상·조건을 정확히 요약하고, 과장 없이.
```
> 짧으면: `1.5배 분량으로 더 작성해줘` → Rank Math 스니펫에 **160자 내외**로 조정

## 5. 파비콘 / 썸네일 (2·6강)

```
[주제] 관련 파비콘을 만들어줘. 1:1 정사각형, 단순한 형태, 작은 크기에서도 식별되게.
```
```
[제목] 썸네일을 만들어줘. 혜택을 과장하지 말고, 실존 브랜드 로고는 넣지 말 것.
```
> 상업 이용 라이선스·상표·인물 권리를 확인하고 사용하세요.

## 6. 정책 페이지 (3·4강)

```
내 블로그 개인정보 처리방침을 만들어줘. 블로그 주제는 [주제], 문의 이메일은 [실제 이메일].
```
> ⚠️ AI 초안 그대로 게시 금지. **실제 수집하는 데이터·실제 사업자/문의 정보와 일치**하게 수정.

---

## AI 사용 원칙 (5강 10단계 요약)
1. 공식 사실을 먼저 수집하고
2. 벤치마크는 **구조만** 참고(문장 복제 금지)하고
3. 프롬프트에 사실·금지사항·광고표시를 명시하고
4. 출력의 **모든 수치를 공식과 대조**하고
5. 본인의 경험·기준을 더해 독창성을 만들고
6. 사람이 최종 검수한 뒤 발행합니다.

"블로그 말투를 학습시켰으니 저작권 문제 없다"는 강사 주장은 **틀립니다.**
