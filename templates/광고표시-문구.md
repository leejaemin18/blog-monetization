# 광고 표시 문구 모음 (복사해서 사용)

근거: 공정거래위원회 추천·보증 심사지침
https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000280130

**위치**: 제목 또는 본문 **첫 부분**. 본문과 시각적으로 구분되게.
**금지**: 본문 중간·맨 끝·댓글·"더보기" 뒤. 영어/해시태그 단독.

---

## 쿠팡 파트너스

```
이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```

## 일반 제휴 링크

```
이 글에는 제휴 링크가 포함되어 있으며, 링크를 통해 상품을 구매하시면
작성자가 판매자로부터 일정액의 수수료를 받습니다. (구매자 추가 부담 없음)
```

## 여행/할인코드 (Trip.com 등)

```
본 글의 예약·구매 링크는 제휴 링크입니다. 링크를 통해 예약하시면 작성자에게
일정액의 수수료가 지급되며, 이는 여러분의 결제 금액에 영향을 주지 않습니다.
```

## AI 가상인물 사용 시 (추가 표기)

```
※ 이 글에 등장하는 인물/후기는 AI로 생성된 가상 예시이며, 실제 사용 후기가 아닙니다.
```

## HTML 박스 버전 (워드프레스 첫 부분 삽입용)

```html
<div style="border:1px solid #e0e0e0;background:#f7f7f7;padding:12px 16px;
     border-radius:8px;margin:0 0 20px;font-size:14px;color:#555;">
  💡 이 글에는 제휴 링크가 포함되어 있으며, 링크를 통해 구매·예약하시면
  작성자가 일정액의 수수료를 받습니다. 구매자에게 추가 비용은 없습니다.
</div>
```

## 체크
- [ ] 제목 또는 첫 문단에 배치했는가
- [ ] "체험 후기 / 홍보성 글 / 소정의 원고료" 만 쓰지 않았는가
- [ ] 한국어로 구체적인 수수료 관계를 밝혔는가
- [ ] 매 게시물마다 넣었는가 (한 번만 넣고 재사용 X)
