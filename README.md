## 범위 (무엇을 다루고, 무엇을 안 다루는가)

| 강의 | 내용 | 이 저장소에서 |
|---|---|---|
| **1·2·3강** | 워드프레스 개설·최적화·애드센스 승인 | **참고용** — "블로그 만들고 설정하는 법"만 익힘 |
| **4·5·6강** | 세컨/서드 블로그 + 제휴마케팅 수익화 | **핵심 작업** |

- **애드센스 기반 블로그**는 이미 개설되어 **승인 대기 중**이며, *제이통관블로그 워드프레스
  프로젝트*에서 **별도로 관리**합니다. 이 저장소는 그 진행을 참조만 합니다.
- 여기서 실제로 굴리는 것은 **제휴 수익화 채널**입니다:
  1. **세컨 블로그 (워드프레스)** — 쿠팡 파트너스 · 네이버 쇼핑커넥트
  2. **서드 블로그 (워드프레스)** — 다른 니치로 확장
  3. **네이버 블로그** — 제휴링크 + 애드포스트

## 이 저장소가 하는 일

| 영역 | 내용 |

| **data/** | 블로그/채널 설정, 키워드 파이프라인, 제휴 오퍼, **제휴 프로그램 디렉터리(100선)**, 콘텐츠 대장, 성과 기록 |
| **tools/** | 키워드 점수화 · 발행 전 컴플라이언스 검사 · 쿠폰 만료 감시 · 진행 대시보드 |
| **templates/** | 글 구조 템플릿, **제휴글 스타일 가이드**, AI 프롬프트, 광고 표시 문구, 할인코드 HTML |
| **extension/** | **개인용 제휴 글 초안 어시스턴트 크롬 확장** — 내 API 키로 서버 없이 바로 사용(직접 모드), 프록시 모드 선택 가능 |
| **checklists/** | 발행 전 / 주간 점검 / 쿠팡 파트너스 가입 |

## 설계 원칙

강의는 **강사 주장**과 **공식 확인 사실**이 섞여 있습니다. 둘을 분리해서 다룹니다.

1. **정책이 수익보다 먼저** — 공정위 추천·보증 심사지침과 쿠팡 파트너스 운영정책, 그리고
   네이버 각 플랫폼(쇼핑커넥트·블로그·카페·지식인) 규정을 어기면 계정 정지·수익 몰수로
   이어집니다. 강의의 일부 기법(목차 클릭 강제 이동, 보상형 클릭, 지식인 도배, 무단 캡처)은
   **그대로 따라하면 안 됩니다.** → [`docs/90-정책-준수-가이드.md`](docs/90-정책-준수-가이드.md)
2. **수치는 전부 미검증으로 취급** — "쿠팡 24시간 전환", "Trip.com 7%" 등은 실행 직전
   공식 페이지에서 재확인하고 확인일을 기록. → [`docs/91-강사주장-vs-검증사실.md`](docs/91-강사주장-vs-검증사실.md)
3. **내 데이터로 판단** — 남의 수익 인증이 아니라 `data/metrics.csv`에 쌓이는 내 숫자로 결정.

## 빠른 시작

```bash
python3 --version                       # 3.9+ (외부 의존성 없음)

$EDITOR data/niche.yaml                  # 세컨/서드 블로그 + 네이버 블로그 설정
python3 tools/dashboard.py               # 진행 상황 확인

$EDITOR data/keywords.csv                # 키워드 후보 입력
python3 tools/kwscore.py                 # 우선순위 계산

python3 tools/compliance.py drafts/내글.md   # 발행 전 정책 검사 (필수)
python3 tools/offers.py --days 7             # 만료 임박 쿠폰 확인
```

## 비용 (강의 기준 · 실행 직전 재확인)

| 항목 | 강의 금액 | 성격 |
|---|---|---|
| 도메인 | 연 20,000~25,000원 | 연 1회 (이미 보유 시 불필요) |
| 호스팅 서버 1대 | 월 31,900원 | 고정비 |
| 블로그 추가 (서버당 최대 3개) | 월 4,000원 | 세컨/서드 블로그용 |
| 키워드 도구 | 월 2~3만원대 | 선택 |

> **서브도메인은 추가 비용 0원.** 도메인 1개만 있으면 세컨·서드 블로그를 무료로 붙일 수 있습니다.
> **네이버 블로그는 완전 무료** — 서버·도메인 없이 바로 시작 가능.
