# 블로그 수익화 프로젝트

프레스런 무료강의(1~6강) 학습노트를 실행 가능한 운영 시스템으로 옮긴 저장소입니다.
워드프레스 블로그를 세팅하고, 구글 애드센스 승인을 받고, 제휴마케팅으로 수익화하는
전 과정을 **문서 + 데이터 + 검수 도구**로 관리합니다.

> 원본: Google Drive `프레스런 무료강의 요약노트` 폴더의 학습노트 6종 (2026-07-31 기준)

---

## 이 저장소가 하는 일

| 영역 | 내용 |
|---|---|
| **docs/** | 6개 강의를 실행 순서로 재편집한 운영 문서 + 정책 준수 가이드 |
| **playbook/** | 30일 실행 로드맵과 하루 루틴 |
| **data/** | 니치 설정, 키워드 파이프라인, 콘텐츠 대장, 제휴 오퍼, 성과 기록 (CSV/YAML) |
| **tools/** | 키워드 점수화 · 발행 전 컴플라이언스 검사 · 쿠폰 만료 감시 · 진행 대시보드 |
| **templates/** | 글 구조 템플릿, AI 프롬프트, 광고 표시 문구 |
| **checklists/** | 발행 전 검수 / 주간 점검 체크리스트 |

## 설계 원칙

강의 내용은 **강사 주장**과 **공식 확인 사실**이 섞여 있습니다. 이 저장소는 둘을 분리해서 다룹니다.

1. **정책이 수익보다 먼저** — 공정위 추천·보증 심사지침과 쿠팡 파트너스 운영정책 위반은
   계정 정지·수익 몰수로 이어집니다. 강의에 나오는 일부 기법(목차 클릭 강제 이동,
   보상형 클릭, 지식인 도배, 홈페이지 캡처 무단 사용)은 **그대로 따라하면 안 됩니다.**
   → [`docs/90-정책-준수-가이드.md`](docs/90-정책-준수-가이드.md)
2. **수치는 전부 미검증으로 취급** — "월 1천만원", "승인율 99%", "쿠팡 24시간 전환",
   "Trip.com 7%" 같은 값은 강사 주장이거나 시점에 따라 변합니다. 실행 직전 공식 페이지에서
   재확인하고 확인일을 기록합니다.
   → [`docs/91-강사주장-vs-검증사실.md`](docs/91-강사주장-vs-검증사실.md)
3. **내 데이터로 판단** — 남의 수익 인증이 아니라 `data/metrics.csv`에 쌓이는 내 숫자로
   다음 행동을 정합니다.

## 빠른 시작

```bash
# 0. 파이썬 3.9+ 만 있으면 됩니다 (외부 의존성 없음)
python3 --version

# 1. 내 블로그 설정을 채웁니다
$EDITOR data/niche.yaml

# 2. 현재 진행 상황 확인
python3 tools/dashboard.py

# 3. 키워드 후보를 넣고 우선순위 계산
$EDITOR data/keywords.csv
python3 tools/kwscore.py

# 4. 글 발행 전 정책 검사 (필수)
python3 tools/compliance.py drafts/내-글.md

# 5. 만료 임박 쿠폰/프로모션 확인
python3 tools/offers.py --days 7
```

## 진행 순서

```
Day 0    사전 준비·예산 확정        docs/01-사전준비-비용.md
Day 1-2  워드프레스 개설 + 최적화    docs/02-워드프레스-세팅.md      (1·2강)
Day 3-5  애드센스 승인용 콘텐츠      docs/03-애드센스-승인.md        (3강)
Day 5    2번째 블로그(제휴용) 개설   docs/04-두번째-블로그.md        (4강)
Day 6+   제휴 프로그램 가입·수익화   docs/05-제휴마케팅.md           (5강)
Day 6+   수익화 글쓰기 루틴          docs/06-수익화-글쓰기.md        (6강)
상시     정책 점검 · 성과 기록       playbook/일일루틴.md
```

전체 일정은 [`playbook/30일-실행로드맵.md`](playbook/30일-실행로드맵.md)를 따릅니다.

## 비용 (강의 기준 · 실행 직전 재확인 필요)

| 항목 | 강의에서 언급된 금액 | 성격 |
|---|---|---|
| 도메인 | 연 20,000~25,000원 | 연 1회 |
| 호스팅(서버 1대) | 월 31,900원 | 고정비 |
| 블로그 추가(서버당 최대 3개) | 월 4,000원 | 선택 |
| 키워드 도구 | 월 2~3만원대 | 선택 |

> 위 금액은 특정 업체 상품 조건이며 변동됩니다. **수익이 0원인 달에도 감당 가능한 예산**인지
> 먼저 확인하고 시작하세요. `data/niche.yaml`의 `budget` 항목에 본인 기준을 적습니다.

- 세무·법률 판단이 필요한 부분(사업자 유형, 세금계산서, 표시광고법 해석)은 전문가에게 확인하세요.
