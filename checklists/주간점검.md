# 주간 점검 체크리스트

매주 1회 (예: 일요일). 15~20분.

## 성과 리뷰
- [ ] `data/metrics.csv`에 이번 주 노출·클릭·전환·수익 기록
- [ ] `python3 tools/dashboard.py` 로 누적 확인
- [ ] 저성과 원인 1개 진단 (키워드/제목/본문/상품/링크/정책 중 병목)
- [ ] 다음 주 개선 실험 1개 정의 (수치 근거 기반)

## 콘텐츠
- [ ] 이번 주 발행 글이 계획대로 나갔는가 (`content_ledger.csv`)
- [ ] 애드센스 심사 중이면 하루 1개 발행 유지되는가
- [ ] 상위 노출/유입이 생긴 글에 내부 링크·보강

## 오퍼·최신성
- [ ] `python3 tools/offers.py --days 7` — 만료 임박 쿠폰 확인
- [ ] 만료된 쿠폰이 들어간 글 수정/삭제
- [ ] 확인일 30일 지난 오퍼 재확인

## 정책 (월 1회는 필수)
- [ ] 쿠팡/네이버/애드센스/공정위 정책 변경 확인 → `data/policy_log.csv`
- [ ] 무료체험 자동결제·도메인 갱신일 임박 여부 (캘린더)

## 위생
- [ ] 워드프레스 코어·테마·플러그인 업데이트 (백업 후)
- [ ] 각 사이트 접속·SSL 정상 여부
