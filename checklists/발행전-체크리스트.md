# 발행 전 체크리스트

모든 글을 발행하기 전에 확인합니다. 제휴 글은 전부, 애드센스용 글은 ★ 항목만.

자동 1차 검사:
```bash
python3 tools/compliance.py drafts/글.md
```
자동 검사를 통과해도 아래를 사람이 최종 확인합니다.

## 정책 (제휴 글 필수)
- [ ] 광고 표시 문구가 **제목 또는 첫 문단**에 있는가
- [ ] "체험 후기/홍보성 글"만 쓰지 않고 구체적 수수료 관계를 밝혔는가
- [ ] 클릭 유도("도와주세요/일단 클릭") 문구가 없는가
- [ ] 콘텐츠를 가리고 방문 조건으로 해제하는 패턴이 없는가
- [ ] 본문 주제와 무관한 상품·브랜드 링크가 없는가

## 링크
- [ ] 공식 파트너스가 생성한 링크인가 (코드 임의 변경 X)
- [ ] 클릭 시 리퍼럴 코드가 붙고 의도한 페이지로 가는가
- [ ] **모바일**에서도 정상 동작하는가

## 정보 최신성
- [ ] 쿠폰 금액·할인율·**유효기간**을 공식 출처에서 오늘 확인했는가
- [ ] 확인일(기준일)을 본문에 표기했는가
- [ ] `data/offers.csv`에 만료일을 등록했는가

## 콘텐츠 품질 ★
- [ ] 독자의 질문을 실제로 해결하는가 (글자 수 채우기 X)
- [ ] 직접경험 / 공식사양 / 제3자후기를 구분했는가
- [ ] 경험하지 않은 것을 경험한 것처럼 쓰지 않았는가
- [ ] 근거 없는 TOP5·순위가 없는가

## 저작권 ★
- [ ] 모든 이미지가 권리 확인된 것인가 (직접제작/미디어킷/라이선스/검수한 AI)
- [ ] 공식 홈페이지 캡처를 무단으로 쓰지 않았는가
- [ ] 경쟁 글의 문구·표·이미지를 복제하지 않았는가

## SEO/형식 ★
- [ ] 제목에 핵심키워드 + 관련어 3~5개 (나열 아님)
- [ ] 메타설명 160자 내외, 실제 내용과 일치
- [ ] 대표 이미지 + 대체텍스트
- [ ] 오탈자 확인
- [ ] 표·버튼이 모바일에서 안 깨지는가

## 발행 후
- [ ] `data/content_ledger.csv`에 기록 (status=발행, ad_disclosure=y)
- [ ] 네이버 서치어드바이저 → 웹페이지 수집 요청 (신규 사이트 한 달간)
- [ ] 필요 시 외부 유입 (지식인/블로그/카페 — 정책 준수)
