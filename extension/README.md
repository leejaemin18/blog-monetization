# 제휴 글 초안 어시스턴트 (개인용 크롬 확장)

강의에 나온 "결제해야 쓰는 자동 글쓰기 프로그램"을 **내가 직접 쓰려고** 만든 **개인용 크롬 확장**입니다.
서버 없이, 내 Anthropic API 키만 있으면 바로 동작합니다.

> **자동 발행 기능은 의도적으로 없습니다** — 스타일 가이드에 맞는 **초안**을 만들어 에디터에 넣는 것까지.
> 사실·링크·광고표시·저작권은 **사람이 최종 검수 후 수동 발행**합니다. (네이버 자동 포스팅은 약관 위반·제재)

## 무엇을 하나
1. 사이드패널에 **제목·키워드·니치·제휴처·채널**을 입력
2. 확장이 **스타일 가이드를 system 프롬프트로 주입**해 Claude를 호출
3. 광고표시 문구 + [사진: 설명] 이미지 자리표시자 + 링크 **자리표시자**가 포함된 초안 생성
4. "에디터에 삽입" 또는 "복사" → 사람이 검수·수정·발행

## 빠른 시작 (개인용 직접 모드 — 서버 불필요)
1. **API 키 발급**: <https://console.anthropic.com> → API Keys → `sk-ant-...` 복사
2. **크롬에 확장 로드**
   - `chrome://extensions` → 우상단 **개발자 모드** 켜기
   - **압축해제된 확장 프로그램을 로드** → 이 `extension/` 폴더 선택
3. 툴바의 확장 아이콘 클릭 → 사이드패널 → **⚙ 설정**
   - **Anthropic API 키** 붙여넣기
   - **모델** 선택: 품질 우선(opus-5) / 균형(sonnet-5) / 저렴·빠름(haiku-4-5)
   - **설정 저장**
4. 워드프레스/네이버 글쓰기 페이지를 연 상태에서 제목·키워드 입력 → **초안 생성** → 검수 → **에디터에 삽입**

> 키는 **이 컴퓨터의 `chrome.storage.local`에만** 저장됩니다. 매번 입력할 필요 없습니다.

## 구조
```
extension/
  manifest.json      MV3 (개인용 v0.2.0)
  background.js      서비스워커 — 내 키로 api.anthropic.com 직접 호출 + 스타일 가이드 주입
  content.js         에디터에 초안 삽입(워드프레스/네이버/일반)
  sidepanel.html/js  입력·⚙설정(키·모델)·생성·삽입·복사 UI
  proxy/             (선택) 여러 대에서 쓰거나 키를 숨기고 싶을 때 쓰는 백엔드
    server.js        API 키를 쥐는 프록시(Anthropic SDK)
    package.json
```

## 두 가지 모드
| 모드 | 언제 | 키 위치 | 설정 |
|---|---|---|---|
| **직접 (기본)** | 나 혼자, 내 PC에서 | `chrome.storage.local` | ⚙ 설정에 API 키 저장 |
| **프록시 (선택)** | 여러 기기/사람, 키 숨김 | 내 서버 | ⚙ 설정에 프록시 URL 입력 (키칸 비움) |

프록시 URL을 넣으면 그쪽이 우선합니다. 실행법:
```bash
cd extension/proxy
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # 절대 깃/코드에 넣지 말 것
npm start                              # http://localhost:8787  → 설정의 프록시 URL 칸에 http://localhost:8787/generate
```

## 키 보관에 대한 솔직한 설명 (중요)
- 이 확장은 **개인용·미배포**를 전제로 API 키를 로컬에 저장합니다. 나만 쓰는 도구이므로 실용적으로 안전합니다.
- **하지 마세요**: 이 확장을 **크롬 웹스토어에 올리거나**, 폴더째 **남에게 공유**하는 것.
  확장을 받은 사람은 저장 방식과 무관하게 키를 꺼낼 수 있고, 키가 유출되면 **내 크레딧으로 비용이 청구**됩니다.
- 여러 명이 쓰거나 배포가 필요하면 **프록시 모드**로 전환하세요(키는 서버만 쥠 + 인증·요청제한·비용상한 추가).
- 키가 새면 콘솔에서 **즉시 폐기(revoke) 후 재발급**하세요.

## 하지 않는 것 (권장)
- 🚫 네이버 자동 포스팅/매크로 (약관 위반·저품질·제재)
- 🚫 사람 검수 없는 무인 대량 발행 (스팸 정책 위반)
- 🚫 키를 넣은 채로 확장을 배포/공유
