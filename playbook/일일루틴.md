# 일일 실행 루틴

세팅이 끝난 뒤 매일 반복하는 루틴입니다. 강의는 하루 5~10개를 권하지만,
**시작은 소량(글 1~2개 + 검수)으로.** 품질과 정책 준수가 물량보다 우선입니다.

대상 채널: **세컨 블로그(워드프레스)** + **네이버 블로그** (검증 후 서드 블로그 추가).
같은 글을 채널에 복제하지 말고, 채널별 독자에 맞게 재작성합니다.

시작 전: `python3 tools/dashboard.py`

---

## 매일 (약 1~2시간)

### 1. 점검 (5분)
- [ ] 정책 변경/공지 있는지 (주 1회는 `data/policy_log.csv` 기록)
- [ ] 오늘 홍보할 상품이 제휴 등록·재고·판매 가능한지
- [ ] 링크 생성 화면의 수수료·제외조건 확인

### 2. 키워드 (10분)
- [ ] 씨앗 키워드/모델명/자동완성 수집 → `data/keywords.csv`
- [ ] `python3 tools/kwscore.py` → A·B 등급 선택

### 3. 콘텐츠 작성 (40~60분)
- [ ] `templates/글-구조-템플릿.md` 골격으로 `drafts/`에 초안
- [ ] AI 초안 사용 시 사실·수치 전수 검증 (`templates/ai-프롬프트.md`)
- [ ] 광고 표시 문구 삽입 (첫 부분)
- [ ] 이미지 권리 확인

### 4. 발행 전 검수 (10분)
- [ ] `python3 tools/compliance.py drafts/글.md` → 오류 0
- [ ] `checklists/발행전-체크리스트.md` 사람 확인
- [ ] 링크 모바일 동작 테스트

### 5. 발행·기록 (10분)
- [ ] 발행 → `data/content_ledger.csv` 기록 (ad_disclosure=y)
- [ ] 네이버 서치어드바이저 수집 요청 (신규 사이트 한 달간)
- [ ] `data/offers.csv`에 쿠폰 만료일 등록

### 6. 외부 유입 (선택, 정책 준수)
- [ ] 관련 질문/커뮤니티에 **완결된 도움**을 주고 필요 시 링크 (도배·자작 금지)

### 7. 성과 기록 (5분)
- [ ] `data/metrics.csv`에 노출·클릭·전환·수익 (내부용)
- [ ] 저성과 원인 1개 · 내일 개선 1개 메모
